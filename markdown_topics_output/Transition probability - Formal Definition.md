# Formal Definition
For a Markov chain with state space S = {s1, s2, …, sr}, the transition probability p_{ij} is defined as p_{ij}=P(X_{n+1}=s_j \mid X_n=s_i), the probability that the chain moves to state s_j at the next step given that it is presently in state s_i. These probabilities satisfy p_{ij}≥0 and \sum_{j=1}^r p_{ij}=1 for each i.
