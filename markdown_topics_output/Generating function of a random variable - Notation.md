# Notation
$h(z)$ denotes the generating function of a single‑parent offspring count $X$; $h_{n}(z)$ denotes the generating function of the total number $Z_{n}$ of individuals in the $n^{\text{th}}$ generation; $k(z)$ denotes the generating function of a generic integer‑valued random variable $X_{j}$; $m=h'(1)$ is the mean of $X$, and $m_{n}=h'_{n}(1)$ is the mean of $Z_{n}$.
