# Proof
The proof of Theorem 6.1 is described as straightforward: one groups together all outcomes x that give the same value of φ(x) (and thus the same value of the derived random variable Y=φ(X)), sums the probabilities of those outcomes, and then computes the weighted average ∑_{x∈Ω}φ(x) m(x). This argument is illustrated in Example 6.6, where the expectation of the number of runs Y is obtained by directly summing Y(x)·P(X=x) over all eight possible three‑coin sequences.
