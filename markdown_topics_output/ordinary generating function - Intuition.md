# Intuition
The ordinary generating function h(z)=\sum_{j=0}^{n}z^{j}p(j) encodes the entire probability mass function of a discrete random variable X in the coefficients of a power series, so that each probability p(j) appears as the coefficient of z^j.

Evaluating h at z=1 yields the total probability (h(1)=1), while derivatives at 1 give moments (h'(1)=\mu_1, h''(1)=\mu_2-\mu_1), linking the generating function to familiar statistical quantities.
