# Intuition
A record of a permutation occurs whenever, scanning the permutation from left to right, the current entry is larger than every entry that has appeared earlier. In other words, it is a new maximum up to that position, so the first element is always a record.

The snowfall example shows that even though the actual amounts vary, only the relative ordering matters: each time a larger snowfall than all previous years is observed, a new record is set.
