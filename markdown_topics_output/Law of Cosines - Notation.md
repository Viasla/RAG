# Notation
\(\alpha\) – the angular coordinate (in radians) of the first endpoint relative to a fixed reference point, with the second endpoint at \((1,0)\) corresponding to angle 0. The chord length \(L\) is expressed as a function of \(\alpha\) using the Law of Cosines. In the context of the simulation, \(\alpha\) is chosen uniformly from \([0,2\pi]\).
