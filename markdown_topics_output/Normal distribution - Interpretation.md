# Interpretation
Using N(x) provides a practical method to estimate probabilities for large sample sizes where exact binomial calculation is cumbersome; for instance, the probability that the number of heads in 1,000,000 fair coin flips lies within a narrow interval can be approximated via the normal distribution.

The convergence of S_n* to the normal distribution implies that, for sufficiently large n, the probability that the average proportion of successes deviates from the expected value p by a small amount can be bounded using normal-tail probabilities.
