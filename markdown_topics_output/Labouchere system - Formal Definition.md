The Labouchere system is a betting procedure where the player writes a list of numbers, usually 1, 2, 3, 4. The bet placed at each step is the sum of the first and last numbers of the current list. If the bet is won, the first and last numbers are deleted from the list; if the bet is lost, the amount of the last bet is appended to the end of the list. The process is repeated using the updated list, and if the list contains only one number, that number is bet. The game continues until the list becomes empty. At that point the player has won the total sum of the original list. The system is designed so that each win removes two numbers and each loss adds one new number, thereby adjusting the bet size depending on past outcomes.
