# Formal Definition
The conditional density of X given Y=y is defined by f_{X|Y}(x|y)=\frac{f_{X,Y}(x,y)}{f_Y(y)} where f_{X,Y} is the joint density and f_Y is the marginal density of Y.

The conditional expected value of X given Y=y is then defined as E(X|Y=y)=\int_{a}^{b} x\,f_{X|Y}(x|y)\,dx, where the integration limits a and b cover the support of X.
