# Proof
Since (X) and (V) are independent standard normal variables, the linear combination (Y=ho,X+sqrt{1-ho^{2}},V) has mean (E[Y]=ho,E[X]+sqrt{1-ho^{2}},E[V]=0) and variance (operatorname{Var}[Y]=ho^{2}operatorname{Var}[X]+(1-ho^{2})operatorname{Var}[V]=1). Because the class of normal distributions is closed under linear combinations of independent normals, (Y) is a normal random variable. This illustrates the general fact that the sum (or any linear combination) of independent normal variables is again normal.
