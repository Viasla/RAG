# Properties
The expected number of records in a uniformly random permutation of size n is approximately \log n (natural logarithm). The simulation values for n=10,20,30 are consistent with this asymptotic result (log10\approx2.3, log20\approx3, log30\approx3.4).

The distribution of the number of records appears to be weakly dependent on n for moderate sizes; probabilities for a given k can be estimated by simulation and later derived exactly (see Example 6.11).

Every permutation has at least one record (the first position) and at most n records (the identity permutation).

The probability that a random permutation has no records beyond the first is 1/e \approx 0.3679 for n\ge10, analogous to the hat‑check problem’s derangement probability.
