# Notation
P – full transition matrix after reordering; Q – transient‑to‑transient block; R – transient‑to‑absorbing block; I – identity matrix of size r; 0 – zero matrix of size r×t; r – number of absorbing states; t – number of transient states.

\(\mathbf{R}\): sub‑matrix of transition probabilities from transient to absorbing states; \(\mathbf{Q}\): sub‑matrix of transition probabilities among transient states; \(\mathbf{N}\): fundamental matrix \((\mathbf{I}-\mathbf{Q})^{-1}\); \(\mathbf{B}=\mathbf{N}\mathbf{R}\): matrix of absorption probabilities; \(\mathbf{t}=\mathbf{N}\mathbf{c}\): vector of expected times to absorption (where \(\mathbf{c}\) is a column vector of ones).
