# Examples
In a three‑coin‑toss experiment, the event E = {at least one head turns up} has complement \tilde{E} = \{TTT\}, the single outcome where no heads occur, and its probability is P(\tilde{E}) = 1/8 while P(E) = 7/8.

When the text defines events A, B, and C in the snow‑and‑rain context, the complement of an event such as B (which is “it will not snow tomorrow”) is the event that “it will snow tomorrow.”
