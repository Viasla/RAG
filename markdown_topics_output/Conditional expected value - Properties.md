# Properties
If X and Y are jointly normal, then f_{X|Y}(x|y) is normal with mean \rho y and variance 1-\rho^{2}, so E(X|Y=y)=\rho y.

The conditional expectation is a linear operator in X for fixed Y, i.e., E(aX+b|Y)=aE(X|Y)+b for constants a,b.

When 0<\rho<1 and y>E(Y), the conditional expectation satisfies E(X|Y=y)<y, expressing regression on the mean.

The law of total expectation holds: E(X)=E[\,E(X|Y)\,].
