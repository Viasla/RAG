# Notation
X_j: the j‑th random variable in the independent trials process.

μ: common mean E(X_j).

σ²: common variance V(X_j).

S_n = Σ_{j=1}^{n} X_j: the total sum of the first n trials.

A_n = S_n/n: the sample average of the first n trials.

V(·): variance operator.

E(·): expectation operator.

σ(·): standard deviation, the square root of variance.
