# Formal Definition
For a discrete probability mass function \(p(j)\) defined on integers \(j\), the associated step function is defined by
\[\bar{p}(x)=\begin{cases} p(j), & \text{if } j-\tfrac12 \le x < j+\tfrac12 \text{ for some integer } j,\\ 0, & \text{otherwise.}\end{cases}\]

Analogous step functions are defined for the $n$‑fold convolutions: \(\bar{p}_n(x)\) for the distribution $p_n$ and \(\bar{p}_n^{*}(x)\) for the standardized distribution $p_n^{*}$.
