# Statement
Let X be a continuous random variable whose range is contained in the interval [−M,M].  For each integer k≥0, define the k-th moment μₖ=∫_{−M}^{M}xᵏf_X(x)dx, where f_X is the density of X.  Then the power series g(t)=∑_{k=0}^{∞} μₖ tᵏ/k! converges for every real t, defines an infinitely differentiable function g(t), and for each n≥0 we have g^{(n)}(0)=μₙ.
