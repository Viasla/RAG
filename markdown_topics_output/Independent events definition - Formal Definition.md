# Formal Definition
A finite set of events {A1, A2, …, An} is mutually independent if for every subset {Ai, Aj, …, Am} of the events we have P(Ai ∩ Aj ∩ … ∩ Am) = P(Ai)P(Aj)…P(Am). Equivalently, for any choice of each event or its complement, the probability of the intersection equals the product of the individual probabilities.

For two events (E) and (F) in a probability space with (P(E)>0) and (P(F)>0), they are independent if and only if [P(Emid F)=P(E)] and [P(Fmid E)=P(F).]  In continuous sample spaces this definition is identical to the discrete case; the conditional probabilities are interpreted using densities when necessary.  The two conditions are equivalent, so checking one suffices to establish independence.
