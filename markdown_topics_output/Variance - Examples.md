# Examples
In a single roll of a fair die, letting X be the face value, the mean is μ=7/2. Computing V(X) via the definition yields V(X)=\frac{1}{6}\big(\frac{25}{4}+\frac{9}{4}+\frac{1}{4}+\frac{1}{4}+\frac{9}{4}+\frac{25}{4}\big)=\frac{35}{12}\approx2.9167, with standard deviation √(35/12)≈1.707.

Using the alternative formula, E(X^2)=\frac{91}{6}, so V(X)=\frac{91}{6}-(7/2)^2=\frac{35}{12}, confirming the previous calculation.

Example 6.25 computes the variance of a uniform \([0,1]\) random variable: \(V(X)=\int_0^1\left(x-\frac12\right)^2dx = \frac{1}{12}\).
