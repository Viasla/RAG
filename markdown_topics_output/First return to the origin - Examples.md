# Examples
Figure 12.1 shows a random walk of length 40; the first return to the origin occurs at time 2, illustrating the definition of $f_{2}$.

Example 12.1 defines $w_n$ as the probability that a first return has occurred by time $n$ in $\mathbb{R}^1$ and shows that $w_* =\sum_{i\ge1}f_{2i}=1$, i.e., eventual return is certain in one dimension.

Example 12.2 introduces the notation $f_{2n}^{(m)}$ and $u_{2n}^{(m)}$ for first‑return and return probabilities in $\mathbb{R}^m$, and states the analogous convolution identity (12.2) for all dimensions $m\ge1$.
