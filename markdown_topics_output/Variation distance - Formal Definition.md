# Formal Definition
For any process X that produces an ordering of {1,2,…,n}, let f_X(π) be the probability that X yields ordering π and let u(π)=1/|Ω_n| be the uniform probability for each ordering π∈Ω_n. The variation distance between X and the uniform random process is defined by \[ \|f_X-u\| = \frac{1}{2}\sum_{\pi\in\Omega_n}\big|f_X(\pi)-u(\pi)\big| . \]

The variation distance between the distribution f_X of a process X and the uniform distribution u on the symmetric group S_n is defined as
$$
\|f_X-u\|\;=\;\max_{T\subset S_n}\;\sum_{\pi\in T}\bigl(f_X(\pi)-u(\pi)\bigr)
\;=\;\frac12\sum_{\pi\in S_n}\bigl|f_X(\pi)-u(\pi)\bigr|.
$$
