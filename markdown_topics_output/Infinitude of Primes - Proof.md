# Proof
Let n be any natural number.  Form the factorial n!=1·2·…·n and the integer N=n!+1.  Since any divisor d of n! also divides n!, and d cannot divide N (otherwise d would divide N−n!=1), N shares no common factor with n!; in particular, N is not divisible by any integer 2,3,…,n.  Therefore either N is itself prime or it possesses a prime divisor p that is larger than n.  If p is not prime, it has a prime factor larger than n, and the argument repeats.  Thus for every n there exists a prime p>n.  As n can be taken arbitrarily large, there must be infinitely many primes.
