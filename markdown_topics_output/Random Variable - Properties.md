# Properties
The distribution function m(\omega) assigns nonnegative numbers to outcomes that sum to 1.

A random variable can represent a sum of independent trials, such as X_1+X_2+X_3+X_4.

Random variables can take on different values depending on the outcome, reflecting the random nature of the experiment.

Simulation results improve with a larger number of trials; the error in probability estimates is roughly bounded by the reciprocal of the square root of the number of trials.

(i)  For every outcome ω∈Ω, P({ω}) = m(ω).  (ii)  The total probability of all outcomes sums to one: ∑_{ω∈Ω} P({ω}) = 1.  (iii)  For any event E, P(E) is nonnegative and at most one.  (iv)  If Ω is finite, the random variable is discrete and the distribution function fully characterizes its probabilistic behavior.
