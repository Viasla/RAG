# Notation
V(X) denotes the variance of a random variable X; D(X)=√V(X) is its standard deviation, also written σ for D(X) and σ^2 for V(X). The mean of X is μ=E(X). For a set of independent variables X_1,…,X_n, S_n=Σ X_j is the sum and A_n=S_n/n is the average.

V(X) denotes the variance of X, also written σ².  V(cX)=c²V(X) for any constant c (Theorem 6.14).  E(X²)‑µ² is an alternative expression for variance (Theorem 6.15).
