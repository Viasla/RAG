# Notation
The number of rising sequences of a permutation D is denoted by r(D) or simply r.

A(n,r) denotes the Eulerian number, i.e., the number of permutations of {1,…,n} with exactly r rising sequences.

\\(\\sigma\\): a permutation of \\(\\{1,\\dots,n\\}\\).

\\(\\sigma^{-1}\\): the inverse permutation of \\(\\sigma\\).

Fall: a position \(k\) with \(\sigma^{-1}(k) > \sigma^{-1}(k+1)\).

\(r\): the number of rising sequences in a permutation.

\(a\): the number of packets in an \(a\)-shuffle.

\(A(n,r)\): the Eulerian number counting permutations of \(n\) elements with exactly \(r\) rising sequences.
