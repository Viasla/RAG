# Formal Definition
For a discrete random variable $X$ with probability mass function $p(x)$, the moment generating function is defined by $g(t)=E(e^{tX})=\sum_{x}p(x)e^{tx}$.

Equivalently, if $X$ takes values $x_1,\dots,x_n$, then $g(t)=\sum_{j=1}^n p(x_j)e^{t x_j}$.

The function $g(t)$ is differentiable for all real $t$ because it is a finite linear combination of exponential functions.
