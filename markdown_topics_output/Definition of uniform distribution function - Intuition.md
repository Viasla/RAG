# Intuition
The uniform distribution function captures the intuitive idea that when no outcome is favored over any other, each outcome should be considered equally likely, reflecting symmetry or fairness in the experiment.

A uniform distribution expresses the intuitive idea that every elementary outcome is equally likely; for a finite set this means each outcome receives the same share of the total probability mass.

Choosing a value uniformly at random from an interval means that every sub‑interval of the same length is equally likely, as illustrated by the probability calculations for r and α.
