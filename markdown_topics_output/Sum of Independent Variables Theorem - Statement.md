# Statement
Let X and Y be independent random variables with density functions f_X(x) and f_Y(y) defined for all real numbers. Then the sum Z = X + Y is a random variable whose density function is given by the convolution of f_X and f_Y: 

f_Z(z) = (f_X * f_Y)(z) = \int_{-\infty}^{+\infty} f_X(z - y) f_Y(y) \,dy.
