# Properties
A distribution may have zero, one, or multiple modes (multimodal).

If f_X is continuous and differentiable, interior modes satisfy f'_X(M)=0 and f''_X(M)<0.

A uniform distribution has no unique mode because its density is constant.

The mode is invariant under translations (X+b) but not under scaling by a factor a\neq1; scaling changes the location of the maximum proportionally.

For symmetric unimodal distributions (e.g., normal) the mode coincides with the mean and median.
