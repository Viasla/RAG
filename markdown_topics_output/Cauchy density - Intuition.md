# Intuition
Because the physical situation is symmetric with respect to the mirror axis (φ=0), the resulting density is symmetric for positive and negative values of the distance B, leading to the same formula for all real B.

The Cauchy density is an example of a heavy‑tailed distribution whose second moment does not exist, which explains why the usual Law of Large Numbers does not apply to samples drawn from it.

Because the variance $\,\mu_2$ is infinite, the average of independent Cauchy‑distributed variables does not converge to a constant but retains the same distribution as each individual observation.
