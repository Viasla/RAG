# Notation
( mathbf{P} ) – transition matrix in canonical form; ( mathbf{Q} ) – (t 	imes t) transient‑to‑transient sub‑matrix; ( mathbf{R} ) – (t 	imes r) transient‑to‑absorbing sub‑matrix; ( mathbf{I} ) – identity matrix; ( mathbf{0} ) – zero matrix; ( mathbf{N} ) – fundamental matrix ((mathbf{I}-mathbf{Q})^{-1}); ( mathbf{B} ) – absorption probability matrix (mathbf{N}mathbf{R}); ( mathbf{Q}^n ) – (n)th power of ( mathbf{Q}); ( m_j ) – minimal steps to absorption from state (s_j); ( p_j ) – probability of not being absorbed in (m_j) steps.
