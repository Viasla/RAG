# Examples
If the sample space S consists of outcomes labelled ω1,ω2,…,ωn, then a common computer simulation algorithm generates a random integer between 1 and n with probability 1/n by computing 1 + ⌊n·rnd⌋ where rnd is a uniform random number in [0,1). This algorithm outputs each integer 1,…,n exactly with probability 1/n.
