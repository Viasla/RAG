# Notation
$m(i|x)$ – probability of observing $i$ successes given the success probability $x$; $b(n,x,i)$ – shorthand for the binomial mass function; $x$ – the probability of success in a single trial; $n$ – number of independent trials; $i$ – number of observed successes; $j=n-i$ – number of failures; $inom{n}{i}$ – binomial coefficient; $B(alpha,eta)$ – beta function; $B(alpha,eta,x)$ – beta density.

The binomial probability mass function is denoted by b(n,p,k).

The notation q=1-p is used for the probability of failure in a single trial.

The combinatorial factor \binom{n}{k} counts the number of ways to choose k successes among n trials.

b(n,p,k) denotes the binomial probability of k successes out of n trials.

Parameters: n – number of Bernoulli trials; p – probability of success in each trial; λ – expected number of successes, λ= np.

In examples the variable j is used in place of k when counting successes.

The symbol b(n,p,x) is used to denote the binomial distribution with parameters n and p and the probability of observing the value x.  In Problem 39 the limit h(N,k,n,x)→b(n,k/N,x) is shown.  The binomial mass function is also expressed implicitly via the binomial coefficient \binom{n}{x} in several examples.
