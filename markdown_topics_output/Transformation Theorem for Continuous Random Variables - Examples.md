# Examples
Exercise 18 demonstrates finding F_Y, F_Z, F_W for linear transforms; Exercise 19 demonstrates finding f_Y, f_Z, f_W for the same transforms; Exercise 20 asks for parameters a and b to map a uniform [c,d] to a uniform [0,1]; Exercise 21 shows that Y = F_X(X) yields a uniform random variable, illustrating the transformation theorem.
