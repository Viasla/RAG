# Proof
Starting from the generating function of the population size $h_{n}(z)$, differentiation gives $h_{n+1}'(z)=h'_n(h(z)),h'(z)$.  Setting $z=1$ and using $h(1)=1$, $h'(1)=m$, and $h_n'(1)=m_n$, we obtain $m_{n+1}=m_ncdot m$.  Repeatedly applying this identity gives $m_n=m^n$, since $m_1=m$.  When $m>1$, each multiplication by $m$ increases the mean, producing exponential growth.
