# Statement
For a branching process with offspring generating function $h(z)$, the generating function $h_n(z)$ of the population size in generation $n$ satisfies the recursive equation $h_{n+1}(z)=h_n(h(z))$.

The extinction probability up to generation $n$ follows the recursion $d_n = h(d_{n-1})$ with initial value $d_1=p_0$.
