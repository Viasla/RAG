# Notation
u_{2m}: probability that a symmetric random walk returns to the origin at time 2m (and 0 at odd times).

f_{2m}: probability that the first return to the origin occurs at time 2m (with f_{0}=0).

u_{0}=1 by definition (the walk is at the origin at time 0).

2^{2n}: number of unrestricted walks of length 2n (each step has two choices).
