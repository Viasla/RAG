# Notation
The set of states is denoted $S=\{s_1,s_2,\ldots,s_r\}$.

A particular state is written $s_i$.

The transition probability from $s_i$ to $s_j$ is $p_{ij}$ and the transition matrix is $P=(p_{ij})_{i,j=1}^r$.

The $i$‑th component of a probability vector $\mathbf u$ represents $\Pr\{\text{initial state}=s_i\}$.
