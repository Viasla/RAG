# Notation
Uniform distribution on \(\Omega\) is denoted by \(m\) where \(m(\omega)=1/n\).  For the reduced coin‑toss sample space \(\overline{\Omega}\) the uniform‑derived probabilities are denoted by \(\bar{m}\).  An arbitrary distribution on \(\overline{\Omega}\) may be denoted by \(\overline{q}\).

The expression 1 + |n (rnd)| is a compact algorithmic notation for uniform discrete sampling; rnd is a uniform random number generator on (0, 1).  The symbol ⌊x⌋ denotes the greatest integer not exceeding x, and it is used to convert the continuous output of a normal approximation back to an integer value in the binomial context.  In the description of the uniform distribution, m(ω) denotes the probability mass function for outcome ω.  The continuous uniform density on an interval [a, b] would be written f(x) = 1/(b–a), though this is not explicitly included in the discrete section.
