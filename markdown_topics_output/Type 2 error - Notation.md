# Notation
α(p) – probability of rejecting the null hypothesis (type 1 error when evaluated at the null p).  β(p) – probability of accepting the null hypothesis when it is false (type 2 error).  n – sample size or number of trials.  m – critical value, the threshold of successes above which the null is rejected.  p – true probability of success under the hypothesis being tested (e.g., 0.6 for the null, 0.8 for the alternative in the example).
