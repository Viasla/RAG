# Interpretation
The joint distribution function gives the likelihood of observing any specific combination of values of the component random variables; it encapsulates all dependence information among them.

If the component variables are mutually independent, the joint distribution factorises as the product of the individual (marginal) distribution functions, i.e., P(̅X=(r1,…,rn))=∏_{i=1}^n P(X_i=r_i).

When some combinations are impossible (e.g., (1,0,1) for the cumulative‑head counts Y_i), the joint distribution assigns probability 0 to those outcomes, reflecting the constraints among the variables.
