# Examples
If each X_i is Poisson with mean m, then f(z)=e^{m(z-1)}. For a Poisson‑distributed N with mean \lambda, g(z)=e^{\lambda(z-1)} and the random sum S_N has generating function h(z)=e^{\lambda(e^{m(z-1)}-1)}.

In the chain‑letter branching model, the offspring distribution of a single parent has generating function f(z). After two generations the total number of descendants has generating function f(f(z)), illustrating the same composition principle for the special case where N itself follows the distribution described by f.
