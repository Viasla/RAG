# Properties
If \(X_1,\dots,X_n\) are mutually independent, their joint distribution function is the product of the individual distribution functions; consequently, any subset of the variables is also mutually independent.  The definition implies that knowledge of any subset does not change the marginal probabilities of the remaining variables.  Mutual independence is a prerequisite for an independent‑trials process (Definition 4.5), where the variables are additionally identically distributed.
