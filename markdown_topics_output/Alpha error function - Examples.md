# Examples
In Example 3.11, a drug company claims that a new aspirin is more effective than the ordinary 60 % success rate.  With n=100 trials, the critical values m=69 through m=73 were found to keep both α(.6) and β(.8) below 5 %.  Choosing m=73 favors a lower type 1 error risk, while m=69 favours a lower type 2 error risk.  If the company desired a 1 % error rate instead, the analysis suggests increasing the sample size n rather than adjusting m alone.
