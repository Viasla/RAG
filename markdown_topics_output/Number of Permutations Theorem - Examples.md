# Examples
• For A={a,b,c}, the six possible permutations are 123, 132, 213, 231, 312, 321, illustrating that 3! = 6.
• The factorial values for n=0 through 10 are shown in Table 3.3, e.g., 4! = 24 and 5! = 120.
• The special case 0! is defined to be 1, consistent with the product interpretation of the empty product.
