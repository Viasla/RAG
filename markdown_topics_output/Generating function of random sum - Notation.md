# Notation
S_N = \sum_{i=1}^{N} X_i \;\text{(random sum)}

X_i \;\text{independent, identically distributed integer‑valued random variables}

N \;\text{independent integer‑valued random variable}

f(z)=E(z^{X_1}) \;\text{probability generating function of each X_i}

g(z)=E(z^{N}) \;\text{probability generating function of N}

h(z)=E(z^{S_N}) \;\text{probability generating function of the random sum}
