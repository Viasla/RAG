# Proof
Let S_a denote the sample space of a‑shuffles. By labeling the a stacks 0,…,a‑1, each cut‑interleaving pair corresponds uniquely to an n‑digit base‑a integer, so there are a^n such pairs. Not all pairs produce distinct orderings, but the cut‑interleaving pairs determine the probability distribution. The preceding theorem gives a bijection between S_{a,b} (the set of cut‑interleaving pairs for an a‑shuffle followed by a b‑shuffle) and S_{ab} (the set for a single ab‑shuffle), and corresponding elements produce the same ordering when applied to the identity. For a given ordering D, let m_1 be the number of elements of S_{a,b} that yield D, and let m_2 be the number of elements of S_{ab} that yield D. The bijection implies m_1 = m_2. Both procedures therefore assign probability m_1/(ab)^n = m_2/(ab)^n to D, establishing the theorem.
