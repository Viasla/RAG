# Examples
No concrete examples of applying the Labouchere system are presented in the provided passage.

Using the canonical example list 1, 2, 3, 4, the initial bet is 1+4=5. If this bet wins, the list becomes 2,3 and the next bet is 2+3=5. If that bet also wins, the list becomes empty and the total win is 1+2+3+4=10. If any bet loses, the last bet amount is appended to the list, e.g., after losing the first 5‑dollar bet the list becomes 1,2,3,4,5, and the next bet would be 1+5=6.

If the process terminates (the list becomes empty) the player wins the sum of the original numbers, which in this example is 10.
