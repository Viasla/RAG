# Examples
In Example 5.8, \(X\sim N(10,3^{2})\). Standardizing gives \(Z = (X-10)/3\); the probability \(P(4 \le X \le 16)\) is computed as \(F_{Z}(2) - F_{Z}(-2) = 0.9772 - 0.0228 = 0.9544\).

To simulate a normal variable with arbitrary \(\mu\) and \(\sigma\), one first generates a standard normal \(Z\) (e.g., via the Box–Muller method) and then transforms it by \(X = \sigma Z + \mu\).
