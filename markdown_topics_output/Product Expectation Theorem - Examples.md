# Examples
Example 6.23: For a point Z=(X,Y) uniformly distributed in the unit square, A=X^2 and B=Y^2 are independent. E(A)=E(B)=∫_0^1 x^2 dx=1/3, so E(AB)=E(A)E(B)=1/9, illustrating the theorem. Example 6.24: With Z=(X,Y) uniform in the unit square, let W=X+Y. Y and W are not independent; E(YW)=7/12 ≠ E(Y)E(W), showing the theorem fails without independence.
