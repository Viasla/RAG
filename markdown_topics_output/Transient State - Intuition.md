# Intuition
A transient state is one that the chain will visit only a limited number of times before moving on to an absorbing state or elsewhere. Intuitively, the process “passes through’’ a transient state but does not get stuck there; after some random number of steps it will leave and never return with probability one.

In an absorbing Markov chain the states that are not absorbing are called transient because a process started in any of them will, with probability one, eventually leave and be absorbed in one of the absorbing states.
