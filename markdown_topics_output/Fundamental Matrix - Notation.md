# Notation
$P$ – transition matrix of a regular (ergodic) Markov chain.
$W$ – limiting matrix whose rows are the stationary distribution vector $w$ (i.e., $W=\mathbf{1}w$).
$I$ – identity matrix of the same size as $P$.
$Z$ – proposed fundamental matrix for ergodic chains, defined by the series $Z=I+(P-W)+(P^2-W)+\cdots$.
$N$ – fundamental matrix for absorbing chains, $N=(I-Q)^{-1}=I+Q+Q^2+\cdots$.
$Q$ – sub‑matrix of $P$ restricted to transient states in an absorbing chain.
$c$ – stationary probability column vector satisfying $Pc=c$.

The fundamental matrix is denoted by N in general contexts.

The fundamental matrix for ergodic chains is denoted by Z.
