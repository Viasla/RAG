# Statement
Let F be a symmetric continuous distribution function, and let α be a fixed real number strictly between 0 and 1. Consider a random walk of length n in which each step has distribution F. Define K_n to be the subscript of the first maximum of the walk, i.e., the unique index k such that S_k > S_0,…,S_k > S_{k-1}, S_k ≥ S_{k+1},…,S_k ≥ S_n. Then as n → ∞ we have P(K_n < nα) → (2/π) arcsin √α.
