# Formal Definition
Let S be the set of all n‑tuples M=(m_1,…,m_n) with each m_j\in{0,…,a-1}. For a given M, let n_i be the count of entries equal to i. Starting from the ordered deck (1,2,…,n), label the first n_0 cards with 0, the next n_1 cards with 1, and so on. The a‑shuffle associated to M is the permutation obtained by placing the cards bearing label i into the positions j for which m_j=i, preserving the relative order of cards with the same label. This mapping is a bijection between S and the set of a‑shuffles, showing that there are exactly a^n a‑shuffles of an n‑card deck.
