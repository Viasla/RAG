# Examples
Exercise 17(a) asks to show that cov(X,Y)=E(XY) E(X)E(Y) as stated in the text.

Exercise 17(b) shows that if X and Y are independent then cov(X,Y)=0, while noting that the converse is not always true.

Exercise 17(c) demonstrates that V(X+Y)=V(X)+V(Y)+2\,cov(X,Y).

Exercise 19 asks for the correlation of independent uniform[0,1] variables X and Y, yielding \rho(X,Y)=0, and further asks for correlations involving Z=X+Y and W=X-Y.

Exercise 20 uses a two‑dimensional standard normal density with parameter \rho and shows that the correlation of X and Y equals the parameter \rho.
