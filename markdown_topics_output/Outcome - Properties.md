# Properties
Outcomes are distinct elements of the sample space and together constitute the entire sample space; each outcome can be assigned a non‑negative probability m(ω) such that the sum over all outcomes equals one; the probability of the elementary event consisting of a single outcome equals the probability assigned to that outcome, i.e. P({ω})=m(ω).  Outcomes serve as the basic units upon which random variables are defined and from which all probabilistic reasoning is built.
