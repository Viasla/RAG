# Examples
Example 11.3 in the Land of Oz example:  with the initial probability vector u = (1/3, 1/3, 1/3) and the known matrix P³, the distribution after three days is u^(3)=uP³=(.401,.198,.401).  This calculation uses Theorem 11.2 to obtain the distribution after n = 3 steps.  The example explicitly shows the multiplication uP³ and the resulting probabilities for each state.
