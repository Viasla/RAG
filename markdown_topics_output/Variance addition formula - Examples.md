# Examples
1. If (X) and (Y) are independent with (V(X)=4) and (V(Y)=9), then (operatorname{cov}(X,Y)=0) and (V(X+Y)=4+9=13). 
2. If (X) and (Y) have (V(X)=4), (V(Y)=9) and perfect positive correlation (ho=1) (so (operatorname{cov}(X,Y)=sqrt{4cdot9}=6)), then (V(X+Y)=4+9+2cdot6=25=(2+3)^2). 
3. If (X) and (Y) have (V(X)=4), (V(Y)=9) and perfect negative correlation (ho=-1) (so (operatorname{cov}(X,Y)=-6)), then (V(X+Y)=4+9-12=1=(2-3)^2).
