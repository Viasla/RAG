# Examples
For n=6 and a=3, take M=(1,0,2,2,0,2). Then n_0=2, n_1=1, n_2=3; cards 1 and 2 receive label 0, card 3 label 1, and cards 4,5,6 label 2. Placing the labelled cards in the positions of M with the same label yields the ordering (3, 1, 4, 5, 2, 6).

Using the coding, the probability that in an a‑shuffle the first card (card 1) ends up in the i‑th position is  \[ \frac{(a-1)^{i-1}a^{n-i}+(a-2)^{i-1}(a-1)^{n-i}+\cdots+1^{i-1}2^{n-i}}{a^{n}} \].
