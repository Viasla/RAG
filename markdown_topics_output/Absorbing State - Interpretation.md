# Interpretation
If a chain is absorbing, starting from any state the process will eventually enter an absorbing state and remain there; in the stepping‑stone model the surviving colour’s probability equals its initial proportion in the array.

In the drunkard’s walk the long‑run behaviour is that the walker will eventually be at home or at the bar and stay there.

Each entry B_{ij} gives the probability that the chain, when started in transient state i, will eventually be absorbed in absorbing state j.\nThe vector t gives, for each transient starting state, the expected number of steps before the chain reaches any absorbing state.\nBecause the rows of B sum to 1, the probabilities of absorption into the various absorbing states form a complete distribution for each starting transient state.
