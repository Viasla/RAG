# Examples
Example 2.2 uses a Monte Carlo procedure to estimate the area under the curve \(y=x^2\) in the unit square by generating random pairs \((x,y)\) and counting the fraction that satisfy \(y\le x^2\); with 10,000 trials the estimate was 0.325, close to the exact value \(1/3\).

The same Monte Carlo idea is applied to estimate π by generating random points in the unit square and counting how many fall inside the inscribed circle of radius ½; the probability of falling inside equals \(\pi/4\), so the estimate of π is \(4\times\)the observed fraction.
