# Proof
Chebyshev’s inequality follows directly from Markov’s inequality applied to the non‑negative random variable (X−μ)^2.

For Bernoulli trials, Var(A_n)=Var(S_n)/n^2=pn(1−p)/n^2=p(1−p)/n, which substituted into Chebyshev’s inequality yields the bound stated above.

Exercise 6 illustrates the derivation of the general bound P(|S_n/n−p|≥ε)≤p(1−p)/(nε^2) using this approach.
