# Notation
a, b – positive integers denoting the number of piles in an a‑shuffle or b‑shuffle;

S_{a,b} – the set of ordered pairs (T_1,T_2) where T_1 is an a‑shuffle and T_2 is a b‑shuffle;

S_{ab} – the set of all ab‑shuffles;

T_1, T_2, T_3 – specific shuffles (or their inverses, unshuffles);

a‑shuffle, b‑shuffle, ab‑shuffle – shuffling operations that cut the deck into a, b, or ab piles and then interleave them;

a‑unshuffle, b‑unshuffle, ab‑unshuffle – the inverse operations that label cards and reconstruct the original ordering;

k_i – the current size of the i^{th} stack during the interleaving process.

D – a deck of n cards.

n – the number of cards in the deck.

a – the number of piles used in an a‑shuffle (or a‑unshuffle).

S – the set of all n‑tuples (m_1,…,m_n) with each m_i ∈ {0,…,a‑1}.

M – a specific element of S, written M = (m_1,…,m_n).

n_i – the count of entries equal to i in M, for 0 ≤ i ≤ a‑1.

Label i – the label assigned to the next n_i cards when constructing the shuffle.
