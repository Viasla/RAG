# Formal Definition
The random variables \(X_1,\dots,X_n\) are mutually independent if for every choice of values \(r_1,\dots,r_n\) one has \[P(X_1=r_1,\dots,X_n=r_n)=P(X_1=r_1)\cdots P(X_n=r_n).\] Equivalently, the joint distribution of the vector \(\bar X=(X_1,\dots,X_n)\) equals the product of the marginal distributions.
