# Notation
s_{ij}: the observed count in the i‑th row and j‑th column of the contingency table.

t_{ij}: marginal totals (row sums t_{11}, t_{12}; column sums t_{21}, t_{22}).

n: total sample size (number of draws).

N: total number of items in the population (sum of all marginals).

a: specific value of s_{11} being evaluated.

h(N, k, n, x): hypergeometric probability \( \frac{\binom{k}{x}\binom{N-k}{n-x}}{\binom{N}{n}} \).
