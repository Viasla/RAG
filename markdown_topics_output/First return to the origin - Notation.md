# Notation
$S_{2k}$ – position of the walk after $2k$ steps; $S_{2k}\neq0$ for $k<m$ in a first‑return event.

$u_{2m}=\Pr\{\text{return to the origin at time }2m\}=\binom{2m}{m}2^{-2m}$.

$f_{2m}=\Pr\{\text{first return at time }2m\}$, with $f_0=0$.

$U(x)=\sum_{m\ge0}u_{2m}x^m$, $F(x)=\sum_{m\ge0}f_{2m}x^m$ – ordinary generating functions.

$w_n$ – probability that a first return has occurred by time $n$; $w_* =\lim_{n\to\infty}w_n$.

$f_{2n}^{(m)}$, $u_{2n}^{(m)}$ – first‑return and return probabilities for a walk in $\mathbb{R}^m$.
