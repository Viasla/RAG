# Historical Notes
The text explains that when a person has a large number $N$ of acquaintances and a small probability $p$ of persuading any one of them to buy the letter, the distribution for the number of letters sold can be approximated by a Poisson distribution, because the binomial distribution with parameters $N$ and $p$ converges to a Poisson distribution as $N\to\infty$ and $p\to0$ with $Np=m$ fixed.
