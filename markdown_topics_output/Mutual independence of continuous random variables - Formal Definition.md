# Formal Definition
Definition 4.7: A family of continuous random variables X1,…,Xn with individual CDFs F1,…,Fn is mutually independent if for every choice of real numbers x1,…,xn the joint CDF satisfies F(x1,…,xn)=F1(x1)⋯Fn(xn).

Theorem 4.2: The same family of continuous random variables is mutually independent if and only if their joint density satisfies f(x1,…,xn)=f1(x1)⋯fn(xn) for all x1,…,xn.
