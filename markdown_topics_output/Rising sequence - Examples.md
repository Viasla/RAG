# Examples
The identity ordering (1,2,…,n) has exactly one rising sequence.

The reverse ordering (n,n‑1,…,1) has n rising sequences, one for each individual card.

If n=5 and D=(2,3,1,4,5) then the rising sequences are (2,3) and (1,4,5), so D has r=2 rising sequences.

Consider \(\sigma=(1,3,5,2,4,7,6)\). Its inverse is \(\sigma^{-1}=(1,4,2,5,3,7,6)\). The inverse has falls after positions 2, 4, 6, and 7, so \(\sigma\) has exactly 4 rising sequences.

The identity permutation \((1,2,\dots,n)\) has a single rising sequence, while the reverse permutation \((n,n-1,\dots,1)\) has \(n\) rising sequences (one after each element).
