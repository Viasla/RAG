# Statement
Theorem 11.7 – For a regular transition matrix P the sequence of powers P^n converges, as n→∞, to a limiting matrix W whose all rows are equal to a strictly positive probability vector w (i.e., w has strictly positive components and the components sum to 1).

Theorem 11.8 – Let W=lim_{n→∞}P^n, let w be the common row of W, and let c be the column vector of all ones. (a) wP=w and any row vector v with vP=v is a scalar multiple of w. (b) Pc=c and any column vector x with Px=x is a scalar multiple of c.
