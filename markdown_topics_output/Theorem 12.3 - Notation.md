# Notation
$u_{2m}$ – probability of returning to the origin at time $2m$;\n$f_{2m}$ – probability of a first return to the origin at time $2m$;\n$U(x)=sum_{m=0}^infty u_{2m}x^m$ – ordinary generating function of the return probabilities;\n$F(x)=sum_{m=0}^infty f_{2m}x^m$ – ordinary generating function of the first–return probabilities;\n$inom{2m}{m}$ – central binomial coefficient.
