# Examples
In the symmetric random walk on ${0,1,dots,N}$ (Gambler's Ruin with $p=q$), the function $f(i)=i$ satisfies $f(i)=\tfrac12 f(i-1)+\tfrac12 f(i+1)$ and therefore is harmonic.

For the biased random walk with right‑step probability $p\neq q$, the function $f(i)=\left(\frac{q}{p}\right)^i$ satisfies $f(i)=p,f(i+1)+q,f(i-1)$ and is harmonic.

In Example 11.11, letting $f(i)$ be the proportion of G genes in state $i$, one checks that $f$ fulfills the harmonic equation, so $f$ is a harmonic function on that Markov chain.
