# Formal Definition
For a non‑negative integer k, a random variable X has a Poisson distribution with parameter \(\lambda>0\) if \[P\{X=k\}=\frac{e^{-\lambda}\lambda^{k}}{k!},\qquad k=0,1,2,\dots\] The parameter \(\lambda\) is both the expected value \(E[X]\) and the variance \(\operatorname{Var}(X)\).
