# Properties
The chi‑squared density has one parameter \(n\), the degrees of freedom, which is usually easy to determine from the problem context (e.g., \((a-1)(b-1)\) for a contingency table). The density is a special case of the gamma density, implying it can be expressed using the gamma function. Tables of chi‑squared density values are used in practice similarly to normal‑distribution tables. For a given significance level (e.g., 5 %), a critical value \(v_0\) can be read from the table; the null hypothesis is rejected when the observed \(\chi^2\) exceeds \(v_0\).
