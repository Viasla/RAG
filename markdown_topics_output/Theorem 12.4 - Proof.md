# Proof
The proof requires showing the equality (b_{2k,2m}=alpha_{2k,2m}) for all (0le kle m).  Exercise 12.1.7 establishes the base cases (b_{2m,2m}=u_{2m}) and (b_{0,2m}=u_{2m}), which coincide with (alpha_{2m,2m}) and (alpha_{0,2m}).  For (1le kle m-1), a recursion is derived by conditioning on the time (2j) of the first return to the origin (the first equalization).  If the path is above the axis during the first (2j) steps, then it must have exactly (2k-2j) additional above‑axis segments after time (2j); if it is below the axis, it must have exactly (2k) above‑axis segments after (2j).  This yields the recurrence: [ b_{2k,2m}= 	frac12 sum_{j=1}^k f_{2j}b_{2k-2j,2m-2j} + 	frac12 sum_{j=1}^{m-k} f_{2j}b_{2k,2m-2j}. ]  Assuming the equality (b_{2ell,2n}=alpha_{2ell,2n}) for all smaller (n), we substitute (alpha) in place of (b).  Using the known expression (alpha_{2ell,2n}=u_{2ell}u_{2n-2ell}) and Theorem 12.2 to evaluate the sums (sum_{j=1}^k f_{2j}u_{2k-2j}) and (sum_{j=1}^{m-k} f_{2j}u_{2m-2j-2k}), the recurrence simplifies to [ b_{2k,2n}= 	frac12 u_{2m-2k}u_{2k}+	frac12 u_{2k}u_{2m-2k} = alpha_{2k,2n}, ] completing the induction and proving the theorem.
