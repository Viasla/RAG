# Proof
Because φ_i are strictly increasing, the event {Yi ≤ y_i} equals {Xi ≤ φ_i^{-1}(y_i)}. The joint probability P(Y1 ≤ y1, Y2 ≤ y2) equals P(X1 ≤ φ1^{-1}(y1), X2 ≤ φ2^{-1}(y2)) = P(X1 ≤ φ1^{-1}(y1))P(X2 ≤ φ2^{-1}(y2)) due to independence of X1 and X2. This factorizes as F_{Y1}(y1)F_{Y2}(y2), proving independence of Y1 and Y2.
