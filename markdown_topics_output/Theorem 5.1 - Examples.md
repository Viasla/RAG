# Examples
Example 5.8 uses Theorem 5.1 to transform a normal variable X∼N(µ=10,σ=3) into the standard normal Z=(X‑10)/3.  By the theorem, F_X(16)=F_Z((16‑10)/3)=F_Z(2) and F_X(4)=F_Z((4‑10)/3)=F_Z(‑2).  The probability P(4≤X≤16)=F_Z(2)−F_Z(‑2)=0.9772−0.0228=0.9544.

The text states that for the linear transformation X=σZ+µ, Theorem 5.1 yields f_X(x)=f_Z((x‑µ)/σ)·(1/σ)=1/(√(2π)σ) exp{−(x‑µ)²/(2σ²)} and F_X(x)=F_Z((x‑µ)/σ), confirming that X is normal with parameters µ and σ.
