# Intuition
A generating function $h(z)$ for a discrete random variable $X$ encodes the entire probability distribution in its power‑series coefficients: $h(z)=E(z^{X})=p_{0}+p_{1}z+p_{2}z^{2}+dots$, where $p_{k}=P{X=k}$. Thus evaluating the function at a particular $z$ is equivalent to taking the expected value of the experiment that yields $z^{X}$.
