# Intuition
The text contrasts independent‑trials processes, where past outcomes have no influence on future predictions, with Markov chains, where only the most recent state matters for predicting the next state; this is illustrated by the picture of a frog jumping among lily pads, each jump governed by fixed probabilities that depend only on the pad the frog is currently on.

In the gambling interpretation each dollar that the casino collects corresponds to a step of the Markov chain; the only payouts occur when the chain enters the absorbing state (the target pattern). Hence the expected total intake equals the expected total payout, which is exactly the expected time to absorption.

An absorbing Markov chain can be visualised as a random walk through partial matches of a pattern; the chain moves forward when the next toss continues the match and jumps back to a shorter prefix when a mismatch occurs, eventually landing in the full‑pattern (absorbing) state.
