# Formal Definition
A standard normal random variable $Z$ is a normal random variable with mean $\mu = 0$ and standard deviation $\sigma = 1$; its probability density function is $f_Z(z) = \frac{1}{\sqrt{2\pi}}\,e^{-z^{2}/2}$ for $z\in\mathbb{R}$, and its cumulative distribution function is $F_Z(z) = \int_{-\infty}^{z} \frac{1}{\sqrt{2\pi}}\,e^{-u^{2}/2}\,du$.

A random variable Z is called standard normal if its probability density function is 
$$f_Z(z)=\frac{1}{\sqrt{2\pi}}\,e^{-z^{2}/2},\qquad -\infty<z<\infty,$$ 
its expected value is $E(Z)=0$ and its variance is $V(Z)=1$.  This is often written as $Z\sim N(0,1)$.
