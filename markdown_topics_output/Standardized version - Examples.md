# Examples
In Exercise 8(b) the random variable from Exercise 1 is standardized, and Chebyshev’s inequality is used to obtain the bounds P(|X*| ≥ 2) ≤ 1/4, P(|X*| ≥ 5) ≤ 1/25, and P(|X*| ≥ 9) ≤ 1/81.  Another example appears in Exercise 15, where a normally distributed variable with mean 10 and variance 3 is transformed to the standard normal X* before computing tail probabilities.
