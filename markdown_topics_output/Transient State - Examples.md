# Examples
In Example 11.13 (the Drunkard’s Walk), the states 1, 2, 3 are transient because the walker eventually reaches one of the absorbing corners 0 or 4 and never returns to the interior states. In the stepping‑stone model described earlier, the intermediate configurations of mixed colors constitute transient states; the chain eventually absorbs into a configuration where all stones have the same color.

In the drunkard’s walk example (Example 11.13) the states 1, 2, 3 are transient, while states 0 and 4 are absorbing; the matrix Q that describes transitions among the transient states is shown as a 4×4 block in the text.

The matrix Q displayed in the computation section (\mathbf{Q}=\begin{bmatrix}1&2&3&4\\2&0.0&0.50&0.00&0.00\\3&0.0&0.50&0.00&0.50\\4&0.0&0.00&0.50&0.00\end{bmatrix}) lists the transition probabilities between the transient states of a five‑block drunkard’s walk.
