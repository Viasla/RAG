# Interpretation
The formula (E=(m^k-1)/(m-1)) grows exponentially with the run length (k) and linearly in (1/(m-1)).  For binary outcomes ((m=2)) it reduces to (2^k-1), matching the familiar expectation for consecutive heads or tails in coin flips.  The result quantifies how rare long runs of a single outcome are: for example, in a fair coin, the expected number of flips to see nine heads in a row is (2^9-1=511).

It also shows that even though any particular run is unlikely, the long runs expected number of trials is finite and can be computed directly from (m) and (k).
