# Examples
For p=7, n=12 and j=9 we have 12 = 5\cdot7^0 + 1\cdot7^1, so (s_0,s_1)=(5,1); and 9 = 2\cdot7^0 + 1\cdot7^1, so (r_0,r_1)=(2,1). Lucas' theorem gives \binom{12}{9} \equiv \binom{5}{2}\binom{1}{1} \pmod{7}. Since \binom{12}{9}=220\equiv3\pmod{7} and \binom{5}{2}=10\equiv3\pmod{7}, the theorem holds for this example.
