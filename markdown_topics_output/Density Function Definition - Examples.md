# Examples
Uniform density on [0,1]: f(x)=1 for 0\le x<1 and f(x)=0 otherwise. Then P(E)=\int_{E}1\,dx equals the length of E, so P([a,b])=b-a.

Uniform density on the unit disc: f(x,y)=1/\pi for x^{2}+y^{2}\le1 and 0 elsewhere. Consequently P(E)=\frac{1}{\pi}\cdot\text{area}(E).

Radial density for the dart‑distance experiment: f(r)=2r for 0<r<1 and 0 otherwise. Here P([a,b])=\int_{a}^{b}2r\,dr=b^{2}-a^{2}, showing a higher likelihood of landing near the rim.
