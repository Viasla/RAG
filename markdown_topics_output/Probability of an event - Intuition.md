# Intuition
Probability is a measure that quantifies how likely an event is to occur; the larger the probability, the more likely the event. The text emphasizes that probability is defined via a distribution function on a sample space and that it satisfies natural properties such as non‑negativity, total mass 1, and monotonicity with respect to set inclusion. It also notes that calculating the probability of a complex event can be simplified by expressing it in terms of simpler events using set operations such as unions, intersections, and complements. The use of the complement and inclusive “or” is highlighted to aid intuitive calculation of probabilities via complementary events.
