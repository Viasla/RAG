# Properties
Theorem 7.1 declares that if X and Y are independent with density functions f_X(x) and f_Y(y), then the sum Z = X+Y has density function f_Z(z) which equals the convolution f_X * f_Y.  This establishes convolution as the operation that produces the density of the sum of independent continuous random variables.  The integral expression is symmetric, so convolution is commutative: f * g = g * f.  It is also associative, allowing repeated convolutions to represent sums of more than two independent variables.
