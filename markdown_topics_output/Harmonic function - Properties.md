# Properties
Harmonic functions are linear: any linear combination of harmonic functions is harmonic.

If the values of a harmonic function are prescribed on all absorbing states (boundary conditions), then there is a unique harmonic extension to the transient states, which gives the absorption probabilities.

For a finite absorbing Markov chain, the vector of absorption probabilities $\mathbf{b}_j$ for a fixed absorbing state $j$ satisfies $\mathbf{b}_j = \mathbf{N}\mathbf{R}_{\cdot j}$, where $\mathbf{N}$ is the fundamental matrix and $\mathbf{R}$ the sub‑matrix of transition probabilities from transient to absorbing states; this algebraic description follows from the harmonic condition.
