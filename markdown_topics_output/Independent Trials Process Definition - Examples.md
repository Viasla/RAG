# Examples
Example 4.14 illustrates an independent trials process: an experiment consists of rolling a fair six‑sided die three times; the random variables \(X_i\) denote the outcome of the \(i\)th roll, each having the common distribution \(m_i\) with probability \(1/6\) for each face. Because the rolls are mutually independent and identically distributed, \((X_1,X_2,X_3)\) forms an independent trials process.

Earlier in the text it is noted that any sequence of outcomes of a Bernoulli trials process, such as \((S,S,F,F,S,\dots)\), forms a sequence of mutually independent events, which is a special case of an independent trials process where the common distribution is \(P(S)=p,\;P(F)=1-p\).

Corollary 6.1 considers an independent trials process $\{X_i\}_{i=1}^n$ and defines the sum $S_n=X_1+\cdots+X_n$ and the average $A_n=S_n/n$, illustrating how the process is used in practice.
