# Intuition
The mean number of individuals in generation $n$ is simply the expected number of children produced by each individual in generation $n-1$ multiplied by the expected number in that previous generation.  If each individual, on average, produces more than one child ($m>1$), then each successive generation, on average, will contain more individuals than the one before, and the increase follows a multiplicative pattern.  This multiplicative pattern naturally results in an exponential increase in the average size of the population over time.
