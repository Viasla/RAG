# Historical Notes
The expected absorption time for an unbiased random walk with absorbing boundaries at 0 and n was first analyzed in the context of the Drunkard’s Walk in Chapter 11.13 of the referenced text. The specific statement that the expected time to absorption starting at state x equals x(n−x) is posed in Exercise 26, where the cases n=4 and n=5 were verified and a hint was provided for a general proof using the recurrence relation for the expected time.
