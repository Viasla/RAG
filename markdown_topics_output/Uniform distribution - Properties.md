# Properties
1. Each outcome in \(\Omega\) receives the same probability value \(1/n\).

2. The probabilities of all outcomes sum to 1: \(\sum_{\omega\in\Omega}m(\omega)=1\).

3. The probability of any subset \(A\subseteq\Omega\) under a uniform distribution is \(P(A)=\frac{|A|}{n}\).

4. Uniformity can be preserved under different representations of the sample space if the mapping preserves counts of outcomes (e.g., the mapping from ordered to unordered dice outcomes would change the count, hence a different distribution may be required).

5. For finite sample spaces a uniform distribution always exists and is unique; for infinite sample spaces it may not be defined or may require different construction.

1.  All outcomes are equiprobable: P(ωi) = 1/n for all i.  2.  For any event A ⊆ S the probability is P(A) = |A|/n, which is linear in the size of A.  3.  The expected value of X is the arithmetic mean of the labels of the outcomes, i.e. E[X] = (1/n)∑ωi.  4.  The uniform distribution on a finite set has the maximum entropy among all distributions on that set.  5.  Uniformity cannot be achieved on an infinite countable set; the sum of an infinite number of equal probabilities would diverge.  6.  For an uncountable set of positive finite length (e.g., [0, 1]) the continuous uniform density f(x) = 1/(b–a) provides the analogous equiprobability across the interval.
