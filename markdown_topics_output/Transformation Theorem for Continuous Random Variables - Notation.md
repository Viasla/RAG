# Notation
X: original random variable; F_X: cumulative distribution function of X; f_X: density function of X; Y = X + b: linear shift; Z = aX: linear scaling (a≠0); W = aX + b: affine transformation; c,d: bounds of a uniform distribution; a,b: constants for affine transformations; F^{-1}: inverse of the strictly increasing CDF; U: uniform random variable on [0,1] used in the inversion method.
