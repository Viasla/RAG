# Proof
From Exercise 17(c) we have V(X+Y)=V(X)+V(Y)+2cov(X,Y).  Let σ(X)=√V(X) and σ(Y)=√V(Y).  Then V(X/σ(X)+Y/σ(Y))=2(1+ρ(X,Y)).  Since variance is non‑negative, 2(1+ρ)≥0, so ρ≥−1.  Similarly, V(X/σ(X)-Y/σ(Y))=2(1−ρ(X,Y))≥0, which forces ρ≤1.  Combining these two inequalities yields −1 ≤ ρ(X,Y) ≤ 1.
