# Intuition
Intuitively, an a‑shuffle cuts the deck into a labelled piles and then interleaves them; performing a b‑shuffle afterwards simply refines the existing labels. The combined effect can be described by a single set of ab labels, showing that the two-step process is equivalent to one ab‑shuffle.

Each entry of the tuple M can be thought of as independently choosing which of the a piles a given position will belong to; the shuffle then corresponds to interleaving these piles while keeping the original order inside each pile.

Because the choices for each position are independent, the total number of possible tuples – and therefore shuffles – is simply the product a·a·…·a = a^n.
