# Notation
The distribution function is denoted by m(ωj), where ωj is an outcome.  The probability that a random variable X does not exceed a value k can be expressed using the distribution function as P(X≤k), e.g., P(X≤4)=2/3 for a die.  The floor function ⌊6r⌋+1 is used to convert a uniform random real r∈(0,1) to a discrete random integer consistent with a given distribution.

Ω denotes the sample space of an experiment, a set of all possible outcomes. ω is an individual outcome. X is the random variable representing the outcome. m(ω) is the distribution function value assigned to outcome ω, i.e., the probability mass of that outcome. P(E) denotes the probability of an event E⊆Ω, calculated as the sum of m(ω) over ω∈E.

F(x) denotes the cumulative distribution function of a random variable X.

S_n^* denotes the standardized version of S_n.

N(x) denotes the cumulative distribution function of the standard normal distribution.

The index itself uses terms like 'joint cumulative distribution function' and 'joint density function' to refer to the functions, while 'marginal distribution function' denotes the distribution of a single component; no alternative symbols are indicated in the provided excerpt.
