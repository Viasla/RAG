# Intuition
An absorbing state is a state that, once entered, cannot be left; the process remains there forever (e.g., home or the bar in the drunkard's walk).

In the stepping‑stone model the configuration eventually collapses to a single colour, which corresponds to the chain being absorbed in a state where all stones share that colour.

An absorbing state can be thought of as a “sink” in a Markov chain: when the process reaches such a state it stops moving and remains there forever, much like a ball that falls into a pit and cannot climb out.
