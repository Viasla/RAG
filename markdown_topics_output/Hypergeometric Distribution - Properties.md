# Properties
The sum of the hypergeometric probabilities over all admissible d satisfies
$$\sum_{d=0}^{\min(D,s)}\binom{D}{d}\binom{S-D}{s-d}=\binom{S}{s},$$
which is Euler’s combinatorial identity stated in Problem 35(b).
When the population size N and the number of successes k grow large with the proportion k/N fixed, the hypergeometric distribution converges to the binomial distribution with parameters n and p (Problem 44).
The distribution can be simulated directly by drawing n items without replacement from a population of N items containing k successes, counting the successes, and returning that count (Problem 41).
