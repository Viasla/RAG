# Examples
A bettor is willing to make a 1 dollar bet giving 2 to 1 odds that Dartmouth will win; this corresponds to a probability of 2/3 for Dartmouth winning.

In Example 1.12, a candidate C has probability 1/5 of winning, so the odds in favor of C are 1/5 : 4/5, which can be expressed as 1:4, 2:8, etc.
