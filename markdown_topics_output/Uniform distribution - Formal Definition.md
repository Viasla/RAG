# Formal Definition
The uniform distribution on a sample space \(\Omega\) containing \(n\) elements is defined by the function \(m\) where \(m(\omega)=\frac{1}{n}\) for every \(\omega\in\Omega\).

Let S be a sample space with cardinality n (0 < n < ∞).  The uniform distribution on S is the probability mass function m(ω) defined by m(ω) = 1/n for every ω ∈ S.  In the discrete case the distribution function is thus a constant 1/n over S, and for any event A ⊆ S the probability is P(A) = |A|/n.
