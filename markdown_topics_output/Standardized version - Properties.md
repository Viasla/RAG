# Properties
(a) For any a > 0, the inequality P(|X*| ≥ a) ≤ 1/a² holds, a consequence of Chebyshev’s inequality applied to the standardized variable.  (b) The standardized variable has mean 0 and variance 1, so its distribution is independent of the original location and scale.  (c) The bounds become tighter as a increases, reflecting the decreasing probability of large deviations from the mean.
