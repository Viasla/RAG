# Intuition
A type 2 error occurs when a statistical test fails to reject a false null hypothesis – in other words, it “accepts” a hypothesis that is actually wrong. In practice this means that a potentially useful drug (or any effect) may be missed because the test concludes it has no effect. This is the opposite of a type 1 error, where a true null hypothesis is incorrectly rejected. The trade‑off between the two errors is that making the test more conservative (e.g., by increasing the critical value m) reduces the chance of a type 1 error but simultaneously raises the chance of a type 2 error, and vice versa. The text illustrates this by showing that raising m lowers the upper‑tail probability of a binomial distribution under the null (α) while lowering it raises the lower‑tail probability under the alternative (β).
