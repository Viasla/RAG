# Interpretation
The value m quantifies the expected reproductive output of an individual; it determines the long‑term fate of the lineage: if m\le1 the process almost surely becomes extinct (extinction probability d=1), whereas if m>1 there is a non‑zero chance of survival (extinction probability d<1).

Because m_n=m^n, the average size of generation n grows exponentially with base m; thus m is the exponential growth rate of the expected population size.
