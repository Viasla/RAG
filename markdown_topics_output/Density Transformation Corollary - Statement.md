# Statement
For a continuous random variable X and a strictly increasing function φ on the range of X, define Y = φ(X). If the densities of X and Y are f_X and f_Y respectively, then f_Y(y) = f_X(φ^{-1}(y)) * d/dy φ^{-1}(y). If φ is strictly decreasing, then f_Y(y) = - f_X(φ^{-1}(y)) * d/dy φ^{-1}(y).
