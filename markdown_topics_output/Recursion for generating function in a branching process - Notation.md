# Notation
$h(z)=p_0+p_1z+p_2z^2+cdots$ denotes the generating function of the single‑parent offspring distribution.

$h_n(z)=E(z^{Z_n})$ denotes the generating function of the population size $Z_n$ in generation $n$.

$m=h'(1)=p_1+2p_2+cdots$ is the mean number of offspring from a single parent; $m_n=h'_n(1)$ is the mean population size in generation $n$.

$d_n=P(Z_n=0)$ is the probability that the process has died out by generation $n$; $d=lim_{n	oinfty}d_n$ is the ultimate extinction probability.
