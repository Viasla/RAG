# Examples
In Example 6.17, the variance of a single die roll is computed as V(X)=35/12≈1.458, illustrating how the formulas V(X)=E(X²)-μ² and V(cX)=c²V(X) work for a single trial, which can be extended to multiple independent die rolls using Theorem 6.9.

If ten independent die rolls are summed, the variance of the sum is 10·(35/12), and the variance of the average of the ten rolls is (35/12)/10, demonstrating the theorem in a concrete setting.
