# Examples
When the patterns have length k = 2, the quantities satisfy AA – AB = BB – BA, so the ratio equals 1 and the game is fair (p_A = p_B = ½). For length k = 3, the differences are never equal; for instance, if A=HTH and B=HHT, one finds BB – BA ≠ AA – AB, giving p_A < ½. Hence the second player always has a winning advantage for any choice of A when k = 3, as predicted by Conway’s formula.
