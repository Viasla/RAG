# Examples
1. For $B=	ext{HTH}$ the martingale argument yields $E(T^{	ext{HTH}})=BB=10$; hence the expected number of tosses until the first appearance of HTH is 10. 2. For $B=	ext{HHH}$ we have $BB=14$, so $E(T^{	ext{HHH}})=14$. 3. When starting from pattern $A=	ext{HT}$ and seeking $B=	ext{HTH}$, the gambler’s expected remaining time is $E_A(T^B)=BB-AB=10-4=6$, again consistent with the martingale reasoning.
