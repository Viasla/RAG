# Formal Definition
Definition 4.5: A sequence of random variables \(X_1,X_2,\dots,X_n\) that are mutually independent and that have the same distribution is called a sequence of independent trials or an independent trials process.

Let $X_1,X_2,\dots ,X_n$ be real‑valued random variables such that the collection \{X_i\}_{i=1}^n is mutually independent and each $X_i$ has the same expectation $E(X_i)=\mu$ and the same variance $V(X_i)=\sigma^2$. The sequence \{X_i\} is called an independent trials process.
