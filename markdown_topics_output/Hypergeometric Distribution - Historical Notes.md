# Historical Notes
Problem 35 introduces the hypergeometric distribution as the model for the number of defective items X in a sample drawn without replacement from a lot of S items containing D defectives, stating “Thus, X is hypergeometric.”

Problem 44 discusses a limiting result for the hypergeometric distribution, showing that when the population size N and the number of successes k grow to infinity while the ratio k/N approaches a fixed p, the hypergeometric distribution converges to the binomial distribution with parameters n and p.
