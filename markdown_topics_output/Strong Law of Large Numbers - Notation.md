# Notation
$S_n=sum_{j=1}^n X_j$, $S_n/n$ denotes the sample average of the first $n$ trials.  The weak law uses this notation; the strong law would involve the same quantities but with almost sure convergence.

S_n = X_1 + ... + X_n denotes the partial sum of the first n random variables.

A_n = S_n/n denotes the empirical average.

E = { ω : lim_{n→∞} A_n = 1/2 } denotes the event that the proportion of heads tends to 1/2.

Ω = {0,1}^ℕ denotes the sample space of infinite sequences of coin toss outcomes.

P denotes the probability measure defined on Ω.
