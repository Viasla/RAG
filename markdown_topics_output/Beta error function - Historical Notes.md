# Historical Notes
In the presented text, the beta error function is introduced in the context of hypothesis testing for a new aspirin additive.  The concept arises directly from the binomial model for success/failure experiments and is used to quantify the likelihood of a type 2 error, that is, failing to reject a false null hypothesis.  The text does not provide a historical origin beyond its role as the complementary function to the alpha error function in classical statistical inference.
