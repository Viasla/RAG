# Examples
For the Cauchy density $f_X(x)=\frac{1}{\pi(1+x^2)}$, the characteristic function evaluates to $k_X(\tau)=e^{-|\tau|}$.

If $Y$ has the same Cauchy density, then $k_Y(\tau)=e^{-|\tau|}$ as well.

For the sum of two independent Cauchy variables $X+Y$, the characteristic function is $k_{X+Y}(\tau)=\big(e^{-|\tau|}\big)^2 = e^{-2|\tau|}$.

If $Z = \frac{X+Y}{2}$, the scaling property gives $k_Z(\tau)=k_{X+Y}(\tau/2)=e^{-2|\tau/2|}=e^{-|\tau|}$, which matches the characteristic function of $X$ and $Y$.

Exercise 6 asks to show that a random variable whose characteristic function is $k_X(\tau)=e^{-|\tau|}$ has density $f_X(x)=\frac{1}{\pi(1+x^2)}$, demonstrating the one‑to‑one correspondence between a characteristic function and its density.
