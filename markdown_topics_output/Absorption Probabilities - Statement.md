# Statement
Theorem 11.6: Let $b_{ij}$ be the probability that an absorbing Markov chain will be absorbed in the absorbing state $s_j$ if it starts in the transient state $s_i$. Let $B$ be the matrix with entries $b_{ij}$. Then $B$ is a $t$‑by‑$r$ matrix and $B = N R$, where $N = (I - Q)^{-1}$ is the fundamental matrix and $R$ is the transient‑to‑absorbing block of the canonical form of the transition matrix.
