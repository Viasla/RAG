# Properties
For any event E with P(E)>0 the conditional distribution satisfies ∑_{ω∈Ω}m_E(ω)=1 and m_E(ω)≥0 for all ω.

If A⊆E then P(A\mid E)=∑_{ω∈A}m_E(ω).

Bayes’ formula follows from the definition: P(E\mid F)=P(F\mid E)P(E)/P(F) for P(F)>0.

If A and B are independent, then P(A\mid B)=P(A); consequently the conditional distribution given B equals the original distribution.

Conditioning on an event of probability zero is not defined in the elementary discrete setting; a limit or regular conditional probability is required in the continuous case.
