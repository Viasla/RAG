# Examples
The program Fixed Vector uses Theorem 11.8 (via computation of the left nullspace of P‑I and normalization) to find the unique fixed row probability vector for regular and ergodic Markov chains, such as the Land‑of‑Oz weather example where w=(0.4,0.2,0.4).

Exercise 31 provides an alternate proof of Theorem 11.8 by applying the above argument to any fixed vector of an ergodic chain.

In a regular chain, the unique stationary distribution has strictly positive entries, which is a special case of Theorem 11.8.
