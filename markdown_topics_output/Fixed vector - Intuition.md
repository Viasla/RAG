# Intuition
A fixed row (or column) vector is a vector that remains unchanged when the transition matrix of the chain is applied; intuitively it represents a steady‑state distribution that the chain settles into after many steps, because the probabilities no longer evolve.

The fixed vector can be thought of as the “balance point’’ of a Markov chain: if the chain starts with that distribution, the probabilities of being in each state do not change from one step to the next, and for an ergodic chain the chain’s state frequencies converge to this vector regardless of the initial state.
