# Intuition
A distribution function assigns a non‑negative weight to each elementary outcome of a random experiment so that the total weight (the sum over all outcomes) equals one; intuitively it tells how likely each possible result is, and the requirement of convergence guarantees that the total probability is well‑defined even when there are infinitely many outcomes.

A distribution function assigns to each elementary outcome ω in the sample space Ω a non‑negative weight that represents the probability of that outcome occurring.

A distribution function gives the probability that a continuous random variable takes a value less than or equal to a specified point, i.e., the accumulated likelihood up to that point.

The text explains that where a density function is large, the random variable is more likely to fall in that region, and the distribution function captures this by accumulating those probabilities from $-\infty$ up to $x$.
