# Intuition
A joint distribution function records the probability of each possible combined outcome of several random variables, so it tells how likely each n‑tuple of individual results is to occur when the experiment is performed.

In the coin‑toss example, the joint distribution of ̅X=(X1,X2,X3) simply gives 1/8 to each of the eight possible triples because the three tosses are independent and equally likely.
