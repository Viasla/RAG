# Proof
The proof starts from the identity $(I-P)M=C-D$ (Equation 11.6) and left‑multiplies by $Z$, using Lemma 11.2 which gives $Z(I-P)=I-W$ and $Zw=w$. This yields $M-WM=C-ZD$. Solving for the $(i,j)$ entry gives $m_{ij}=1-z_{ij}r_j+(wM)_j$, where $r_j=1/w_j$. Setting $i=j$ and using $m_{jj}=0$ gives $(wM)_j=z_{jj}r_j-1$. Substituting this back into the expression for $m_{ij}$ eliminates $(wM)_j$ and yields $m_{ij}=(z_{jj}-z_{ij})r_j$, i.e. $m_{ij}=(z_{jj}-z_{ij})/w_j$. The derivation relies only on the properties $Zc=c$, $wZ=w$, and $Z(I-P)=I-W$ established in Lemma 11.2.
