# Formal Definition
For a numerically‑valued random variable X with mean μ=E(X), the variance is defined by V(X)=E\big((X-μ)^2\big).

An equivalent computational formula, proved in Theorem 6.6, is V(X)=E\big(X^2\big)-μ^2.

Definition 6.5 states that for a real‑valued random variable \(X\) with density \(f(x)\) and mean \(\mu=E(X)\), the variance is \(\sigma^2 = V(X) = E\big((X-\mu)^2\big)\).

Theorem 6.13 provides an equivalent integral formula: \(\sigma^2 = \int_{-\infty}^{\infty} (x-\mu)^2 f(x)\,dx\).
