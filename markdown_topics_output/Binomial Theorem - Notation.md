# Notation
Binomial coefficient: \u2113{n}{r} or C(n,r) denotes the number of r‑element subsets of an n‑set.

Falling factorial notation: (n)_r = n(n‑1)…(n‑r+1).

Pascal’s triangle arranges the coefficients \u2113{n}{r} in rows indexed by n and columns by r.

The expansion (a+b)^n uses superscript n for the power and the sum notation Σ_{r=0}^{n}.
