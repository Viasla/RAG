# Proof
Define X_j as the indicator variable for the jth trial, taking value 1 if the jth outcome is a success and 0 otherwise. For each j, E(X_j)=0·(1-p)+1·p=p. Since S_n = X_1+X_2+⋯+X_n, the expectation of a sum equals the sum of expectations, so E(S_n)=E(X_1)+E(X_2)+⋯+E(X_n)=p+ p+⋯+ p (n times)=np.
