# Formal Definition
For a probability distribution m on a sample space Ω, the probability of an event E⊆Ω is defined by P(E)=∑_{ω∈E}m(ω).  The distribution m assigns non‑negative weights to elementary outcomes ω and satisfies ∑_{ω∈Ω}m(ω)=1.  This definition immediately yields the basic properties of a probability measure.  For the specific calculation presented, m(A)=2/5, m(B)=2/5, m(C)=1/5 and therefore P(E)=m(A)+m(C)=3/5 for E={A,C}.  In the coin‑toss example, each of the 8 elementary paths has m(ω)=1/8, so P(tilde{E})=1/8 and consequently P(E)=7/8.
