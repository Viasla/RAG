# Formal Definition
A uniform distribution function on a finite sample space \(\Omega\) with \(n=|\Omega|\) assigns the same probability \(1/n\) to every elementary outcome \(\omega\in\Omega\); consequently, for any event \(A\subseteq\Omega\) the probability is \(P(A)=|A|/n\).

For a finite sample space Ω with |Ω|=n, a uniform distribution is the probability mass function m defined by m(ω)=1/n for every ω∈Ω, satisfying ∑_{ω∈Ω}m(ω)=1 and m(ω)≥0.

For a countably infinite sample space Ω={ω₁,ω₂,…}, a uniform distribution would require a constant a such that m(ω_i)=a for all i. The axioms of probability demand a≥0 and ∑_{i=1}^{∞}a=1, which is impossible because the series either diverges (if a>0) or equals 0 (if a=0).

If a variable X is chosen uniformly from an interval [a,b], the probability that X lies in a sub‑interval [c,d]⊆[a,b] is (d‑c)/(b‑a), i.e., the length of the sub‑interval divided by the length of the whole interval; similarly, for a point chosen uniformly in a region, the probability equals the area of the sub‑region divided by the total area.
