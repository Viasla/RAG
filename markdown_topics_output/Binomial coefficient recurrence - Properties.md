# Properties
Binomial coefficients satisfy $inom{n}{r}=inom{n}{,n-r,}$, exhibiting symmetry.

They obey the additive property that the sum of a row in Pascal’s triangle equals $2^n$, reflecting the binomial theorem $sum_{r=0}^ninom{n}{r}=2^n$.

The entries in Pascal’s triangle can be generated recursively via $inom{n}{r}=inom{n-1}{r}+inom{n-1}{r-1}$, which is the standard recurrence relation for binomial coefficients.
