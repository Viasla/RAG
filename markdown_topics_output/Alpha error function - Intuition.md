# Intuition
Alpha(p) is the probability that, when the true success probability equals p, a random sample of size n yields at least m successes and thus causes the test to reject the null hypothesis.  A larger critical value m makes it harder to see a high number of successes, thereby lowering the chance that a true null hypothesis is mistakenly rejected.  Conversely, a smaller m increases the chance of rejecting the null when it is actually false, but also increases the chance of a type 2 error.
