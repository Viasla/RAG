# Statement
For a geometrically distributed random variable T with success probability p and q=1−p, the memoryless property states that for all integers r,s ≥ 0, P(T > r + s | T > r) = q^s.

For a random variable T that possesses the memoryless property, the conditional probability satisfies \(P(T > r + s \mid T > r) = P(T > s)\) for all non‑negative r and s. In particular, the exponential distribution with rate λ and the geometric distribution satisfy this equality.
