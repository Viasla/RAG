# Intuition
The moment generating function g(t)=E(e^{tX}) expands into a power series whose coefficients are the moments μ_k=E(X^k). Thus g(t) encodes all moments of X. For a discrete random variable with a finite range, the set of all moments uniquely determines the probability mass function, because each mass point contributes a distinct exponential term e^{t x_j} with coefficient p(x_j). Consequently, if two such distributions have the same mgf, they must assign the same probabilities to the same mass points.
