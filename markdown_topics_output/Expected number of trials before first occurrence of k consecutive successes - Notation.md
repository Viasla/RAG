# Notation
(m): number of equally likely outcomes per trial; 
(k): desired length of a consecutive run of a particular outcome; 
(E): expected number of independent trials until the first occurrence of a run of length (k); 
States ({1,2,dots ,k}) in the Markov chain represent the current length of the run; 
Absorbing state (k) corresponds to having achieved the run of length (k).
