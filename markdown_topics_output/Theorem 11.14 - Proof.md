# Proof
Let X₀, X₁,… be a Markov chain with transition matrix **P** started in state sᵢ and let Y₀, Y₁,… be an independent chain with the same matrix **P** started with initial probabilities given by **w**. Construct the joint chain **P*** on state pairs (s_k,s_l) with transition probabilities **P***((k,l),(i,j))=P(k,i)P(l,j). Since **P** is regular, there exists N such that **P**^N(i,j)>0 for all i,j; hence **P*** is also regular and any pair can be reached from any other pair in at most N steps. Let T be the first time the two chains meet, i.e. X_T=Y_T. Then P(T>n)→0. For any n≥T, X_n and Y_n are in the same state, so P(X_n=j|n≥T)=P(Y_n=j|n≥T). Multiplying by P(n≥T) yields P(X_n=j,n≥T)=P(Y_n=j,n≥T). Since Y_n has distribution **w** for every n, the second term tends to w_j and the first term tends to w_j as well. The difference between P(X_n=j,n≥T) and P(X_n=j) is bounded by P(n<T), which tends to 0; thus P(X_n=j)→w_j for each j. Therefore **u** **P**ⁿ→**w**.
