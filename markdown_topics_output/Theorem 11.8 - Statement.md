# Statement
Theorem 11.8 states that for a regular (or ergodic) transition matrix P, the left nullspace of the matrix P‑I has dimension 1, equivalently there is a unique fixed row probability vector w satisfying wP=w.

If P is the transition matrix of an ergodic Markov chain and x is a column vector satisfying Px = x, then all components of x are equal; i.e., x is a constant vector.
