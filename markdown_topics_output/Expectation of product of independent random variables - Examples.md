# Examples
Example 6.9: A coin is tossed twice. Let X_i be 1 if the i‑th toss is heads and 0 otherwise. X_1 and X_2 are independent with E(X_i)=1/2, so E(X_1·X_2)=E(X_1)E(X_2)=1/4.

Example 6.10: A single coin toss defines X=1 for heads, 0 for tails, and Y=1−X. Though E(X)=E(Y)=1/2, the variables are not independent; X·Y is always 0, so E(X·Y)=0≠E(X)E(Y). This illustrates that the theorem fails without independence.
