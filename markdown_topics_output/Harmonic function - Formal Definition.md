# Formal Definition
For a Markov chain with transition probabilities $p_{ij}$, a function $f$ defined on the states is called harmonic (on the set of transient states) if for every transient state $i$ we have $f(i)=\sum_j p_{ij}\,f(j)$.  This equation expresses that $f(i)$ equals the expected value of $f$ after one step from $i$.
