# Notation
Z_n: random variable giving the number of individuals in generation n.

h(z)=\sum_{k\ge0}p_k z^k: probability generating function of the number of offspring produced by a single parent.

h_n(z): probability generating function of Z_n.

p_k: probability that a parent produces exactly k offspring.

m=h'(1)=\sum_{k\ge0}k p_k: mean number of offspring per parent.

m_n=h_n'(1): mean number of individuals in generation n.

d: smallest root in [0,1] of the equation z=h(z), representing the extinction probability.
