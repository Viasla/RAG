# Intuition
The generating function h_n(z) encodes the full probability distribution of the random variable Z_n, the number of individuals in the nth generation, by assigning to each possible count k the coefficient of z^k equal to P(Z_n=k).

Because offspring from different parents are independent, the distribution in the next generation is obtained by composing the one‑step generating function h(z) with the current generating function, reflecting the combinatorial aggregation of independent family trees.
