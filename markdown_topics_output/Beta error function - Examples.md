# Examples
1.  In Example 3.11, the null hypothesis is p = 0.6 and the alternative is p > 0.6.  For a sample size n = 100 and a chosen critical value m, α(0.6) represents the probability of a type 1 error.  If the alternative value is p = 0.8, then β(0.8) = 1 – α(0.8) is the probability of a type 2 error.  The text shows that with m = 69 the power (1 – β) is sufficient to keep the type 1 error below 5 %, while m = 73 keeps the type 2 error below 5 %.
