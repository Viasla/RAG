# Statement
Theorem 3.8 gives the exact probability that a collector obtains every one of the n distinct pictures after buying m ≥ n boxes of Wheaties, each box containing one of the n pictures chosen uniformly at random.  The probability is expressed by the alternating sum

P_{n,m}=1-{nchoose1}Bigl(rac{n-1}{n}Bigr)^m+{nchoose2}Bigl(rac{n-2}{n}Bigr)^m-cdots+(-1)^{,n-1}{nchoose n-1}Bigl(rac{1}{n}Bigr)^m,

where the k‑th term corresponds to the probability that a specific set of k pictures is missing.  The theorem is an instance of the inclusion–exclusion principle applied to the event “all n pictures are seen”.
