# Properties
The Monte Carlo estimator converges to the true value as the number of trials \(n\) increases; the expected error decreases at a rate of at most \(1/\sqrt{n}\) with 95 % confidence, as illustrated by the 10,000‑trial example yielding an error around 0.01.

The procedure is applicable to any measurable subset of the unit square (or any space where a uniform distribution can be defined), making it a versatile tool for numerical integration and probability estimation.
