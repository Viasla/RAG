# Proof
Multiplying the matrix equation $(\mathbf I-\mathbf P)\mathbf M = \mathbf C-\mathbf D$ (Equation 11.6) on the right by the stationary row vector $\mathbf w$ and using $\mathbf w(\mathbf I-\mathbf P)=\mathbf 0$ gives $\mathbf w\mathbf C-\mathbf w\mathbf D=\mathbf 0$. Since $\mathbf w\mathbf C$ is a row vector of all ones and $\mathbf w\mathbf D$ has entries $w_i r_i$, we obtain $(1,1,\dots,1) = (w_1 r_1, w_2 r_2,\dots,w_n r_n)$. Equating components yields $w_i r_i =1$, i.e. $r_i = 1/w_i$ for each state $s_i$.
