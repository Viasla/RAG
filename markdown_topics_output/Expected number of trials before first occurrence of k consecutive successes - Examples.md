2.  The text notes that in the decimal expansion of π, starting at the 24,658,601‑st digit, there is a run of nine consecutive 7’s.  If the digits were produced randomly, the average distance needed to locate such a run would be about 111 million digits, showing that the observed run occurs far earlier than the expectation.
