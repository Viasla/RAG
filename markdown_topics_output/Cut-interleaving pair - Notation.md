# Notation
S_a : the set of all a‑shuffles (all cut‑interleaving pairs for a given a).

S_{a,b} : the set of ordered pairs of an a‑shuffle followed by a b‑shuffle applied to the identity ordering.

(d_1\dots d_n)_a : an n‑digit base‑a integer representing a cut‑interleaving pair.

m_1, m_2 : the numbers of elements of S_{a,b} and S_{ab} respectively that produce a given ordering D.
