# Formal Definition
Let Z_1,Z_2,\dots,Z_N be random variables describing a branching process. Each parent in generation k produces j offspring with probability p_j, independently of all other parents and of previous generations. The mean number of offspring per individual is m=\sum j\,p_j. The extinction probability d is the smallest non‑negative solution of d=f(d), where f(z)=\sum p_j z^j is the offspring generating function.
