# Notation
The distribution function is denoted by m(ω) or m(n) when Ω is indexed by natural numbers; the total probability is written Σ_{ω∈Ω}m(ω)=1, and probabilities of events are written P(E)=Σ_{ω∈E}m(ω).

The symbol m(ω) is commonly used to denote the value of the distribution function at outcome ω.

Σ_{ω}m(ω)=1 expresses the normalization condition.

The distribution function is denoted $F_X(x)$ or simply $F(x)$.

The piecewise formulas $F_X(x)=0$ for $x\le0$, $F_X(x)=\sqrt{x}$ for $0\le x\le1$, and $F_X(x)=1$ for $x\ge1$ illustrate the notation in Example 2.13.
