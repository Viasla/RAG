# Examples
Given m(A)=2/5, m(B)=2/5, m(C)=1/5, the event E={A,C} has probability P(E)=m(A)+m(C)=3/5 by Property 4 for disjoint events.

In a coin–toss experiment with three independent tosses, each of the eight outcomes ω_i has probability 1/8. The event E of at least one head has complement E^c={TTT}, so P(E^c)=1/8 and P(E)=1−1/8=7/8 by Property 5.
