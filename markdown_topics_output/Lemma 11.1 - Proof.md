# Proof
In the discussion following Theorem 1.7, it was noted that each entry in the vector Py is a weighted average of the entries in y. The largest weighted average that could be obtained in the present case would occur if all but one of the entries of y have value M0 and one entry has value m0, and this one small entry is weighted by the smallest possible weight, namely d. In this case, the weighted average would equal dm0 + (1 - d)M0. Similarly, the smallest possible weighted average equals dM0 + (1 - d)m0. Thus, M1 - m1 ≤ (dm0 + (1 - d)M0) - (dM0 + (1 - d)m0) = (1 - 2d)(M0 - m0).
