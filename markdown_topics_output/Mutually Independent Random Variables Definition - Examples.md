# Examples
In Example 4.10 the three Bernoulli random variables \(X_1,X_2,X_3\) representing the outcomes of three independent fair‑coin tosses satisfy the definition, because each joint outcome \((a_1,a_2,a_3)\) occurs with probability \(1/8=(1/2)(1/2)(1/2)\).

Example 4.14 shows three i.i.d. dice‑roll variables \(X_1,X_2,X_3\); for any triple \((r_1,r_2,r_3)\) the joint probability is \((1/6)^3\), confirming mutual independence.

Example 4.13 defines two binary variables \(S\) (smoking) and \(C\) (cancer) for a sample of 60 people; the joint probability \(P(C=1,S=1)=3/60\) does not equal the product \(P(C=1)P(S=1)=10/60\cdot13/60\), illustrating a violation of the definition.
