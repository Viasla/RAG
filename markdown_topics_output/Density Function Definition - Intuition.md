# Intuition
A density function describes how probability mass is distributed over a continuous sample space; the probability of an event is visualised as the area under the graph of the density over that event’s region.

For a very small interval [x,x+dx] the probability is approximately the height of the density at x multiplied by the width dx, i.e., P([x,x+dx])≈f(x)dx, reinforcing the area‑under‑curve interpretation.
