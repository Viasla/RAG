# Formal Definition
Let X1,…,Xn be random variables with individual outcome sets Ri. The joint random variable ̅X=(X1,…,Xn) has sample space Ω=R1×R2×…×Rn, the Cartesian product of the Ri. The joint distribution function of ̅X is the function that assigns to each n‑tuple (r1,…,rn)∈Ω the probability P(X1=r1, X2=r2, …, Xn=rn).
