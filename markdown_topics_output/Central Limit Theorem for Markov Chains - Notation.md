# Notation
S_j^{(n)}: total number of visits to state s_j during the first n steps; w_j: jth component of the fixed probability row vector w (the equilibrium distribution); σ_j^2: asymptotic variance per step defined by σ_j^2 = 2 w_j z_{jj} - w_j - w_j^2; z_{jj}: jth diagonal entry of the deviation matrix Z = (I-P+1ρ)^{-1}; P: transition matrix; I: identity matrix; ρ: stationary distribution row vector.
