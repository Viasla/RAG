# Properties
Using the variance identity V(X+Y)=V(X)+V(Y)+2cov(X,Y) and its counterpart for X–Y, one obtains 0≤V(X/σ(X)±Y/σ(Y))=2(1±ρ), which implies the universal bounds –1≤ρ≤1.

If X and Y are independent, then cov(X,Y)=0 and consequently ρ(X,Y)=0; however, the converse need not hold—zero correlation does not guarantee independence.

Correlation is invariant under linear transformations of the form X' = aX+b and Y' = cY+d with a,c>0, because ρ(X',Y')=ρ(X,Y).

The correlation coefficient of a pair of standardized variables (mean 0, variance 1) equals their covariance, i.e., ρ(X,Y)=cov(X,Y) when V(X)=V(Y)=1.
