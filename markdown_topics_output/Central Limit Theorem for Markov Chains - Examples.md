# Examples
In the Ehrenfest urn model with 2n balls, the equilibrium probability of having i balls in the first urn is w_i = Δ{2n}{i}/2^{2n}. For a fixed i, the random variable S_i^{(n)} counts the number of times the chain visits state i over n steps. By the central limit theorem for Markov chains, the normalized variable (S_i^{(n)}-n w_i)/±sqrt{n σ_i^2} converges to a standard normal as n→∞, where σ_i^2 is computed from the deviation matrix of the Ehrenfest transition matrix.
