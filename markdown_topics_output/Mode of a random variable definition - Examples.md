# Examples
For a normal distribution N(\mu,\sigma^2) the density is symmetric and attains its maximum at x=\mu, so the mode M=\mu.

For an exponential distribution with rate \lambda>0 the density f(x)=\lambda e^{-\lambda x} is decreasing on [0,\infty), so the maximum occurs at the left endpoint x=0; thus the mode is M=0.

For a uniform distribution on [a,b] the density is constant, so every point in [a,b] attains the same maximal value; the mode is not unique (any point in the interval may be called a mode).
