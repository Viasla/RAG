# Formal Definition
Under the null hypothesis of independence, the probability of a specific cell count s_{11}=a given fixed marginals t_{21}, t_{22}, total sample size n, and overall total N is given by the hypergeometric probability: \[ P(s_{11}=a) = \frac{\binom{t_{21}}{a}\,\binom{t_{22}}{n-a}}{\binom{N}{n}} \].

The p‑value for the test is the sum of these hypergeometric probabilities for all tables that are at least as extreme as the observed one (i.e., for a ranging from the observed count up to the maximum possible count).
