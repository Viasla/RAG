# Notation
The notation \(\binom{a}{b}\) denotes the binomial coefficient, i.e. the number of ways to choose (b) elements from a set of (a) elements without regard to order.

{n choose k} denotes binomial coefficient, i.e., number of ways to choose k elements from a set of n elements.

(1+x)^n denotes the binomial expansion ∑_{k=0}^n {n choose k}x^k.

Coefficient of x^n in a polynomial P(x) is denoted [x^n]P(x).
