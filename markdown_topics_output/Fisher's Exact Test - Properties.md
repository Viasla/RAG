# Properties
The test is exact: it does not rely on large‑sample approximations.

It conditions on the marginal totals, treating them as fixed, and computes probabilities using the hypergeometric distribution.

It is appropriate for small sample sizes or sparse tables where chi‑square approximations may be inaccurate.

The p‑value is computed by summing hypergeometric probabilities for all tables at least as extreme as the observed one.
