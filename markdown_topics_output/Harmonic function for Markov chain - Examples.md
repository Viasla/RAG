# Examples
(a) For any harmonic function, repeated application of the transition matrix preserves the function: f = P^n f for all n≥1.

(b) Taking the limit as n→∞ gives f = P^∞ f, showing that the value of a harmonic function at a transient state is a weighted sum of its values at absorbing states via the matrix B.

(c) Consequently, if a player starts in a transient state i, the expected final fortune equals the weighted sum of absorbing-state fortunes: ∑_k b_{ik} f(k) = f(i).
