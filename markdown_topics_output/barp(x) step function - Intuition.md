# Intuition
The function \(\bar{p}(x)\) provides a way to view a discrete probability mass function \(p(j)\) as a piecewise‑constant (step) function on the real line, so that integrals and Fourier transforms can be applied as if the distribution were continuous.

By extending the mass at each integer \(j\) over the interval \([j-\tfrac12,\,j+\tfrac12)\), the step function mimics a histogram representation of the discrete distribution.
