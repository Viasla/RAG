# Formal Definition
For a countably infinite sample space Ω={ω₁,ω₂,ω₃,…} a distribution function m:Ω→[0,1] is defined exactly as in Definition 1.2 for finite Ω, except that the series Σ_{ω∈Ω}m(ω) must converge and satisfy Σ_{ω∈Ω}m(ω)=1. In other words, m is a function assigning probabilities to each ω such that the infinite sum of these probabilities exists and equals one.

A distribution function is a function m:Ω→[0,1] such that for every ω∈Ω, m(ω)≥0 and the total mass satisfies Σ_{ω∈Ω}m(ω)=1.

For a continuous real‑valued random variable $X$, the cumulative distribution function (also called the distribution function) is defined by $F_X(x)=P(X\le x)$.

If $X$ possesses a density $f$, then $F(x)=\int_{-\infty}^{x}f(t)\,dt$, and $\frac{d}{dx}F(x)=f(x)$.
