# Statement
Theorem 3.5 (Intermediate Binomial Coefficient Integer Theorem): When computing the binomial coefficient \(\binom{n}{k}\) by the multiplicative formula \(\frac{n\,(n-1)\dots (n-k+1)}{k!}\) and performing the multiplications and divisions in an alternating order, every intermediate result is an integer, and none of these intermediate integers exceed the final value \(\binom{n}{k}\).
