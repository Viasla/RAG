# Properties
If a constant c multiplies X, then D(cX)=|c|\cdot D(X) (since V(cX)=c^2 V(X)).

Adding a constant does not change standard deviation: D(X+c)=D(X).

For independent random variables X and Y, the variance of their sum is additive, so the standard deviation of X+Y is \sqrt{V(X)+V(Y)}.

For n independent identically distributed variables with common standard deviation \sigma, the sum S_n has standard deviation \sigma\sqrt{n}, and the average A_n has standard deviation \sigma/\sqrt{n}.
