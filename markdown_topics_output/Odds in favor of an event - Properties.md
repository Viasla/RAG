# Properties
Given odds r:s, the associated probability is p = r/(r+s).

Given probability p, the odds ratio is r/s = p/(1-p).

Scaling odds by a common factor does not change the implied probability (e.g., 1:4 and 2:8 are equivalent).

Odds can be converted to fair betting payouts: a bet at r:s odds pays s dollars if the event occurs and costs r dollars if it does not.
