# Interpretation
The value f(x) itself is not a probability; it can exceed 1 (e.g., f(3/4)=3/2 in the radial example) and the probability of any single point is zero because \int_{\{x\}}f=0.

Instead, f(x) measures the relative likelihood of outcomes near x; integrating f over a set yields the total probability of that set.

The density encapsulates the entire probability law of X, since all event probabilities are recoverable by integration.
