# Examples
Example 6.20 computes E(X) for X∼Uniform[0,1] as ∫_0^1 x dx = ½, which is a special case of Theorem 6.11 with φ(x)=x and f_X(x)=1 on [0,1].

Example 6.21 finds the expected distance X from the centre of a unit disk when points are uniformly chosen; here φ(x)=x and the density f_X(x)=2x on [0,1] give E(X)=∫_0^1 x·2x dx = 2/3, illustrating Theorem 6.11 with a non‑uniform density.

Example 6.22 evaluates the expected waiting time Z with density f_Z(z)=2(1−z) on [0,1]; again E(Z)=∫_0^1 z·2(1−z) dz = 1/3, an application of Theorem 6.11.
