# Properties
The characteristic function of a sum of independent random variables factorises: $k_{X+Y}(\tau)=k_X(\tau)k_Y(\tau)$, as shown by the transition from $k_X(\tau)=e^{-|\tau|}$ to $k_{X+Y}(\tau)=e^{-2|\tau|}$.

Scaling a random variable by a constant $c$ changes its characteristic function according to $k_{cX}(\tau)=k_X(c\tau)$, exemplified by $k_Z(\tau)=k_{X+Y}(\tau/2)$.

If two random variables have the same characteristic function, they have the same probability distribution, as used to deduce $f_Z = f_X = f_Y$ from $k_Z = k_X = k_Y$.

The characteristic function of the Cauchy distribution is $e^{-|\tau|}$, a real‑valued even function that decays exponentially in $|\tau|$.
