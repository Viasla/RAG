# Statement
Theorem 10.1: Let X be a discrete random variable with finite range {x_1,x_2,…,x_n} and distribution function p. Its moment generating function g(t)=∑_{j=1}^{n} e^{t x_j}p(x_j) is uniquely determined by p, and conversely, knowing g(t) uniquely determines the set {x_j} and the probabilities {p(x_j)}.
