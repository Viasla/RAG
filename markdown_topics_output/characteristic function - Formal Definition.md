# Formal Definition
The characteristic function $k_X(\tau)$ of a random variable $X$ with density $f_X(x)$ is defined in the text by the integral $k_X(\tau) = \int_{-\infty}^{+\infty} e^{i\tau x} f_X(x)\,dx$. For the Cauchy density $f_X(x)=\frac{1}{\pi(1+x^2)}$, this becomes $k_X(\tau)=\int_{-\infty}^{+\infty} e^{i\tau x}\frac{1}{\pi(1+x^2)}\,dx$.
