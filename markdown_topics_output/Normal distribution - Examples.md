# Examples
In Exercise 15, students are instructed to plot the cumulative distribution of S_n* for n = 10, 50, and 100 and to overlay it with the normal distribution N(x).  This visual comparison demonstrates how the normal curve increasingly matches the binomial cumulative distribution as n grows.

The table of Gallup Poll accuracy provides empirical data on election results, but does not directly involve the normal distribution; it is included only to contrast exact percentages with theoretical expectations that may be approximated by a normal curve.
