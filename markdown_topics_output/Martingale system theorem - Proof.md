# Proof
Li employed the martingale theorem to argue that because all bets are fair (each bet has expected value zero), the expected net change in the gamblers’ fortunes is zero. Thus the expected amount of money the casino collects, $E(T^B)$, must equal the expected amount it pays out, $BB$. This argument is equivalent to showing that the gambler’s fortune process is a martingale and applying the optional stopping theorem at the stopping time when pattern $B$ first appears.
