# Historical Notes
Theorem 4.3 states that if (X_{1}, X_{2}, ldots, X_{n}) are mutually independent continuous random variables and (phi_{1}(x), phi_{2}(x), ldots, phi_{n}(x)) are continuous functions, then the transformed random variables (phi_{1}(X_{1}), phi_{2}(X_{2}), ldots, phi_{n}(X_{n})) are mutually independent.  The statement is noted to hold also for mutually independent discrete random variables, and a proof can be found in Rényi (1970).
