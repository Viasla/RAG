# Formal Definition
For the random variable X defined as the distance on the wall, the cumulative distribution function for B>0 is F(B)=1-(π/2-\arctan(B))/\pi, and the corresponding probability density function is f(B)=1/[\pi(1+B^2)] for all real B.

The Cauchy density is given by the formula $f_X(x)=\frac{1}{\pi\,(1+x^2)}$, $-\infty<x<+\infty$.

Its characteristic function is $k_X(\tau)=\int_{-\infty}^{+\infty}e^{i\tau x}\,\frac{1}{\pi(1+x^2)}\,dx = e^{-|\tau|}$ for all $\tau\in\mathbb{R}$.

The second moment of the Cauchy density is $\mu_2 = \int_{-\infty}^{+\infty}\frac{x^2}{\pi(1+x^2)}\,dx = \infty$, demonstrating that the variance does not exist.
