# Formal Definition
For a discrete random variable X with probability mass function p(j) supported on non‑negative integers, the ordinary generating function is defined as h(z)=\sum_{j=0}^{\infty}z^{j}p(j).

Equivalently, if g(t)=E(e^{tX}) is the moment‑generating function, then h(z)=g(\log z) and g(t)=h(e^{t}).
