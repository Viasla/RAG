# Properties
The raw sum \(S=\sum_{\pi\in\Omega_n}|f_X(\pi)-u(\pi)|\) satisfies \(0\le S\le 2\), so the normalised variation distance \(\|f_X-u\|=S/2\) lies in \([0,1]\). The distance is symmetric: \(\|f_X-u\|=\|u-f_X\|\). For riffle‑shuffle processes the probability \(f_X(\pi)\) depends only on the number r of rising sequences in \(\pi\), allowing the variation distance to be computed via a sum over r rather than over all n! permutations.

Variation distance is always non‑negative and equals zero if and only if f_X equals the uniform distribution. It is symmetric: \|f_X-u\|=\|u-f_X\|. It satisfies the triangle inequality, making it a metric on the space of probability distributions. In the riffle‑shuffle example the distance roughly halves after each additional shuffle once the process is beyond five shuffles, illustrating rapid convergence to uniformity.
