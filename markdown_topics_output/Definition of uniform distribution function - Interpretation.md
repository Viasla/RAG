# Interpretation
Under a uniform distribution the probability of an event is interpreted as the proportion of favorable outcomes among all possible outcomes when all outcomes are equally likely.

The uniform distribution treats all outcomes as having no distinguishing features that affect likelihood; each outcome receives an identical weight in the probability measure.

The probabilities p=1/4, p=1/2 and p=1/3 obtained in the three simulation cases are interpreted as the proportion of geometric measure (area for the (x,y) case, length for the r and α cases) of the favorable set to the total measure, which is exactly the definition of a uniform distribution.
