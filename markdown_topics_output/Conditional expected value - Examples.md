# Examples
For a bivariate standard normal pair (X,Y) with correlation coefficient \rho, the conditional density of X given Y=y is normal with mean \rho y and variance 1-\rho^{2}. Consequently E(X|Y=y)=\rho y.

In Galton’s height study, if the fathers' heights are modelled as 2.7X+68 and the sons' heights as 2.7Y+68 with (X,Y) standard normal and correlation 0.5, then the expected son’s height given a father’s height h is 68+0.5\frac{h-68}{2.7}\times2.7 = 68+0.5(h-68), illustrating regression toward the mean.
