# Formal Definition
The normal distribution, denoted N(x), is defined as the area under the normal density curve from negative infinity up to the value x:  N(x) = P(Z ≤ x), where Z is a standard normal random variable with mean 0 and variance 1.

In the context of binomial trials with success probability p, the standardized variable S_n* = (S_n – np)/√(npq) converges in distribution to a standard normal as n becomes large.  The cumulative distribution function of S_n* is compared to N(x).
