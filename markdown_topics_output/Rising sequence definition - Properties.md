# Properties
• A rising sequence is a maximal run of increasing consecutive integers in a permutation.
• Consecutive elements in the permutation that are not part of any longer increasing consecutive block form distinct rising sequences.
• In a riffle shuffle model, each possible ordering (except the identity) is generated by a unique cut-interleaving pair, and rising sequences help classify the structure of the resulting ordering.
• The identity ordering has the maximum possible number of rising sequences (n), corresponding to each card forming its own sequence.
• The number of rising sequences is invariant under the specific interleaving, depending only on the cut and the interleaving structure.
• In the example provided, the ordering has three rising sequences, reflecting how the interleaving of two stacks produces runs of increasing numbers.
