# Properties
The cumulative distribution function of \(X\) can be expressed in terms of the standard normal CDF: \(F_{X}(x) = F_{Z}((x-\mu)/\sigma)\).

The probability density function of \(X\) is obtained from the standard normal density \(\phi(z)\) by \(f_{X}(x) = \phi((x-\mu)/\sigma)\cdot(1/\sigma) = \frac{1}{\sigma\sqrt{2\pi}} e^{-(x-\mu)^{2}/(2\sigma^{2})}\).

Standardization is a linear transformation that preserves the shape of the normal distribution while shifting the location and rescaling the spread.

Because standard normal tables are widely available, standardization eliminates the need to produce separate tables for each (\(\mu,\sigma\)) pair.
