# Formal Definition
α(p)=∑_{k=m}^{n} b(n,p,k), where b(n,p,k) denotes the binomial probability P(K=k)=\binom{n}{k}p^k(1-p)^{n-k}.  Thus α(p) gives the upper‑tail probability of a binomial(n,p) distribution exceeding the threshold m.  In the aspirin example, α(.6) is the probability of a type 1 error when the true effect is 60 %.  The complementary probability β(p)=1−α(p) gives the probability of a type 2 error for a given alternative p.
