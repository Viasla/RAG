# Properties
If X and Y are independent, their ordinary generating functions multiply: h_{X+Y}(z)=h_X(z)h_Y(z).

The ordinary generating function is related to the moment‑generating function by the change of variables z=e^{t}: h(z)=g(\log z) and g(t)=h(e^{t}).

For a shifted variable Y=X+a, the ordinary generating function satisfies h_Y(z)=z^{a}h_X(z) (implicit from the polynomial form).

For a scaled variable Y=bX, the ordinary generating function satisfies h_Y(z)=h_X(z^{b}) (when b is an integer).
