# Examples
Example 6.14 applies the law to compute the expected number of rolls $T$ in a game of craps: 
$$E(T)=sum_{j=2}^{12}E(T|X=j)P(X=j),$$
where $X$ is the first roll and $S$ is the number of subsequent rolls. Using the geometric distribution for the second stage and summing over all possible first‑roll outcomes yields $E(T)=557/165approx3.375$.
