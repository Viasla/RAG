# Properties
Mutual independence requires the intersection probability property to hold for every possible subcollection of events. Pairwise independence, where only the condition holds for every pair of events, does not guarantee mutual independence. The equality P(A1∩…∩An)=P(A1)…P(An) is necessary but not sufficient for mutual independence, as shown by counterexamples in Exercises 7 and 8.

1. Independence is symmetric: if (E) is independent of (F), then (F) is independent of (E).  2. Independence implies the product rule (P(Ecap F)=P(E)P(F)).  3. If (P(E)=0) or (P(F)=0), independence is vacuous; the definition requires positive probabilities.  4. Checking one of the conditional equations, say (P(Emid F)=P(E)), automatically guarantees the other.  5. For independent events the covariance (Cov(mathbb{1}_E,mathbb{1}_F)=0).  6. Independence extends to collections of events: a family ({E_i}) is mutually independent if every finite subcollection satisfies the product rule.
