# Statement
If X_1, X_2, ..., X_n is an independent trials process of real‑valued random variables with E(X_i)=μ and V(X_i)=σ^2, define S_n = X_1 + X_2 + … + X_n and A_n = S_n / n. Then E(S_n)=n μ, E(A_n)= μ, V(S_n)= n σ^2, V(A_n)= σ^2 / n. Furthermore, defining S_n^* = (S_n – n μ) / sqrt(n σ^2) yields E(S_n^*)=0 and V(S_n^*)=1.
