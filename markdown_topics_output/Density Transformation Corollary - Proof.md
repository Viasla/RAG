# Proof
This result follows from Theorem 5.1 by using the Chain Rule.  Theorem 5.1 states that F_Y(y) = F_X(φ^{-1}(y)) for strictly increasing φ, and F_Y(y) = 1 - F_X(φ^{-1}(y)) for strictly decreasing φ. Differentiating these expressions with respect to y gives f_Y(y) = f_X(φ^{-1}(y)) * d/dy φ^{-1}(y) for increasing φ, and f_Y(y) = - f_X(φ^{-1}(y)) * d/dy φ^{-1}(y) for decreasing φ. The negative sign arises because d/dy φ^{-1}(y) is negative when φ is decreasing. This completes the proof.
