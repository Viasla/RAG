# Formal Definition
A Markov chain with transition matrix P is called *regular* if there exists a positive integer k such that every entry of P^k is strictly positive (i.e., all states can be reached from any other state in exactly k steps). In the text this is expressed by the property that, after a certain number of steps, the rows of P^k become identical, giving the same state probabilities for any initial state.

A Markov chain is called a regular chain if there exists a positive integer n such that the n‑th power of its transition matrix P, denoted P^{n}, has only positive entries (no zeros).
