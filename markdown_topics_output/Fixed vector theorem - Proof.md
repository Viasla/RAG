# Proof
Since P is regular, P^n → W as n→∞.  Multiplying by P, P^{n+1} = P^n P → W P.  But P^{n+1} also converges to W, so W = W P, giving wP = w.  If vP = v, then v = vP^n for all n, and taking limits yields v = vW = r w where r is the sum of the components of v, so v is a scalar multiple of w.  For the column vectors, Px = x implies x = P^n x, hence x = W x.  Since W has identical rows, W x has all equal components, so x is a scalar multiple of the all‑ones vector c.  Thus the only fixed row (up to scaling) is w and the only fixed column (up to scaling) is c.
