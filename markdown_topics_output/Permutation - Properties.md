# Properties
The total number of permutations of a finite set with $n$ elements is $n!$.

The total number of $k$‑permutations of an $n$‑element set is $n(n-1)dots(n-k+1)=rac{n!}{(n-k)!}$.

By definition, a permutation is a bijection, so it preserves cardinality and is invertible.

The notation $(n)_r$ (falling factorial) satisfies $(n)_r=rac{n!}{(n-r)!}$, linking permutations with factorial expressions.
