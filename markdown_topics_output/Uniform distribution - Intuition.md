# Intuition
A uniform distribution reflects a situation where no outcome is privileged or distinguished from any other by physical or logical reasoning; it embodies the principle of symmetry and fairness, assigning the same probability to each elementary event in the sample space.

A uniform distribution embodies the idea that no outcome is preferred over another: every possible result of the experiment has the same chance of occurring.  For a finite set of size n, this means that each element is equally likely, with probability 1/n.  In practice this is what one means when one says that a random draw is “uniform” – it is simply a fair choice among all possibilities.
