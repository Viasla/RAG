# Historical Notes
Theorem 12.3 provides an explicit closed–form for the probability that a symmetric simple random walk on the integers returns to the origin for the first time at time $2m$.  This result, derived using generating–function techniques, follows the development of Theorem 12.1 (return probability) and Theorem 12.2 (convolution relation).

Theorem 12.3 was introduced in Chapter 12 as an application of generating‑function techniques to random‑walk problems, following the earlier development in Theorem 12.2 and Example 12.1. It extends the methodology used to compute probabilities of return by calculating expected counts of equalizations.
