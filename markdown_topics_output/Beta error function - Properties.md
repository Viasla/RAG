# Properties
•  β(p) = 1 – α(p) for each p.  •  For fixed n, β(p) decreases as the critical value m is lowered, because more outcomes fall into the rejection region.  •  β(p) increases as m is increased, since fewer successes lead to rejection.  •  For a given alternative p, β(p) is largest when p is close to the null value; thus more trials n are required to achieve a small β when the effect size is small.  •  In the binomial setting, α(p) is the upper tail probability of the binomial distribution with parameters (n,p), so β(p) is the corresponding lower tail probability.  •  The functions α and β together describe the power curve of a test; the power is 1–β(p).  •  Selecting m between the values that satisfy α < 0.05 and β < 0.05 ensures both error probabilities are controlled in the described example.
