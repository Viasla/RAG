# Examples
Problem 35(a) asks to compute the hypergeometric probability that a sample of s items contains exactly d defectives using the formula above.
Problem 38(b) asks for the probability that a sample of 5 items taken without replacement from a lot of 20 items with 5 defectives contains exactly one defective, which is evaluated with the same hypergeometric pmf.
Problem 41 requests a computer algorithm that simulates a hypergeometric random variable with parameters N, k, and n.
Problem 44 shows that if N and k tend to infinity while k/N→p, the hypergeometric pmf approaches the binomial pmf $b(n,p,x)$.
