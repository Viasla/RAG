# Notation
V(X) – variance of X

σ^2 – alternative symbol for variance

σ or D(X) – standard deviation, defined as √V(X)

μ – expected value E(X)

c – constant multiplier

X_i – individual independent random variables

S_n=\sum_{i=1}^n X_i – sum of n variables

A_n=S_n/n – sample average

The variance of \(X\) is denoted by \(\sigma^2\) or \(V(X)\).
