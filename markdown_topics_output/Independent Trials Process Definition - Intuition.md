# Intuition
An independent trials process captures the intuitive situation in which the same elementary experiment is performed many times, each performance having exactly the same chance of each possible outcome and the outcome of one performance does not affect any other. In everyday language it models repeated coin tosses, die rolls, or any Bernoulli‑type trial where each trial is a fresh, unchanged copy of the original experiment.

An independent trials process models a sequence of repeated experiments or observations in which each trial yields a real‑valued outcome that does not influence the outcomes of any other trials; the trials are assumed to have the same probability law, so that the mean and variance are the same for every trial.
