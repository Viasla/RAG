# Notation
The uniform distribution on a finite set \(\Omega\) of size \(n\) is often denoted \(U_n\) or written as \(m(\omega)=1/n\) for every \(\omega\in\Omega\).

m(ω) – probability mass (or distribution) assigned to outcome ω.

Uniform on a finite Ω: m(ω)=1/|Ω|.

Uniform on a countably infinite Ω would be m(ω)=a for all ω, which is untenable.

The text uses the informal notation “choose … at random from [a,b]” to denote a uniform selection over the interval [a,b].
