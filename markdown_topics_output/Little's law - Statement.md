# Statement
Little's law for queues states that the expected number of customers in the system, denoted N, equals the product of the arrival rate λ and the expected waiting time T, i.e. N = λ T.  Equivalently, the expected waiting time is given by T = N/λ.

Little's law states that for a stable queuing system the expected number of customers in the system (N) equals the arrival rate (λ) multiplied by the expected waiting time (T), i.e., N=λT. This can be rearranged as T=N/λ. The text presents the specific expression for an M/M/1 queue where the traffic intensity ρ=λ/μ<1: N=ρ/(1-ρ) and T=ρ/(λ(1-ρ))=1/(μ-λ).
