# Properties
The Poisson generating function has the closed‑form expression $h(z)=e^{m(z-1)}$, which follows from the exponential series identity.

Differentiating $h(z)$ and evaluating at $z=1$ yields $h'(1)=m$, confirming that the expected number of letters passed on is $m$.

The variance of the Poisson distribution equals its mean $m$, a fact noted in the text by stating that “the variance is larger in this case” when compared with the binomial case with the same mean.
