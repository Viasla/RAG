# Historical Notes
The alpha error function is introduced in the context of hypothesis testing to quantify the probability of a type 1 error, i.e. the probability of rejecting a true null hypothesis.  Its use is exemplified in the aspirin example where a new drug’s effectiveness is compared to a baseline of 60 % success.  In this setting, the function is used to choose a critical value that keeps the probability of a false positive low while balancing the risk of a type 2 error.
