# Examples
1. For a fair six‑sided die, the distribution function assigns m(ωj)=1/6 for each j=1,…,6, so that P(X≤4)=2/3 because two of the six outcomes (1,2,3,4) satisfy the event X≤4. 2. For a coin toss with outcomes H and T, the distribution function assigns m(H)=1/2 and m(T)=1/2. 3. In a custom example with outcomes ω1, ω2, ω3, the distribution function is m(ω1)=1/2, m(ω2)=1/3, and m(ω3)=1/6, and these probabilities can be realized by labeling a six‑sided die or by generating a random real number and mapping intervals to outcomes.

Example 1.6 – Die roll: Ω = {1,2,3,4,5,6}. For a fair die m(i) = 1/6 for i=1,…,6. The event E = {2,4,6} has probability P(E)=m(2)+m(4)+m(6)=1/2. 

Example 1.7 – Coin tossed twice (ordered outcomes): Ω = {HH, HT, TH, TT}. With equal likelihood, m(HH)=m(HT)=m(TH)=m(TT)=1/4. The event E = {HH, HT, TH} (at least one head) has P(E)=3/4 and the event F = {HH, HT} (head on first toss) has P(F)=1/2. 

Example 1.8 – Coin tossed twice (number of heads): Ω = {0,1,2}. The same probabilities arise from the ordered representation but are aggregated: m(0)=1/4, m(1)=1/2, m(2)=1/4. 

Example 1.9 – Election among three candidates: Ω = {A,B,C}. If A and B have the same chance and C has half that of A or B, then m(A)=m(B)=2m(C) and m(A)+m(B)+m(C)=1, yielding m(A)=m(B)=1/3 and m(C)=1/6.
