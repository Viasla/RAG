# Examples
Example 6.14 computes the expected total number of rolls T in a game of craps by conditioning on the outcome X of the first roll. Using the law of total expectation, E(T)=∑_{j=2}^{12}E(T|X=j)P(X=j), and the conditional expectations E(T|X=j) are evaluated for each possible first‑roll value, yielding E(T)=557/165≈3.375.
