# Intuition
The number of ways to permute a set of n distinct elements can be visualized by assigning the first position to any of the n elements, then the second position to any of the remaining n-1 elements, then the third to any of the remaining n-2, and so on until the last position must receive the sole remaining element; this sequential choice process builds intuition that the total number of distinct orderings is the product of these decreasing numbers.
