# Intuition
The theorem provides an asymptotic approximation for the probability that a sum of independent, identically distributed integer‑valued random variables equals a particular integer value. In the context of branching processes, its form is used for comparison with the limiting probabilities of the population size, showing a structural similarity between the two limiting behaviours.

The main difficulty in proving a CLT for discrete integer‑valued random variables is that the distribution functions p_n^*(x) are only defined at points j/√n, so they do not form a simple function over ℝ.  By extending each discrete distribution to a step function τ̅p(x) (equal to p(j) on the interval (j‑½, j+½)) we obtain a genuine density function on ℝ and can then apply Fourier‑analytic techniques.  The extra sinh factor in the modified moment generating function τ̅g_n^*(t) tends to 1, so the limit behaviour is the same as in the continuous case, yielding convergence to the normal density.
