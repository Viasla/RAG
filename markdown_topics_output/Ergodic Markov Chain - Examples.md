# Examples
Example 11.16: The two‑state transition matrix \(P = \frac{1}{2}\begin{pmatrix}0 & 1\\ 1 & 0\end{pmatrix}\) allows movement from any state to any other state, so the chain is ergodic, but it is not regular because odd powers cannot return a state to itself and even powers cannot move a state to the opposite state.

Example 11.17 (Ehrenfest urn model): The transition matrix given in the text (rows labelled 0–4) yields the property that starting from state 0, after an even number of steps the chain is in states 0, 2, or 4, and after an odd number of steps it is in states 1 or 3. Hence every state can eventually be reached from any other, making the chain ergodic, yet it fails to be regular.
