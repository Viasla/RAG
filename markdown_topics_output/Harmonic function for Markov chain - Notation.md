# Notation
The state space is split into transient states and absorbing states, leading to the canonical block form of the limit transition matrix

 P^∞ = lim_{n→∞} P^n = 
   egin{pmatrix} 0 & B\ 0 & I end{pmatrix},

where B contains the absorption probabilities from transient to absorbing states and I is the identity on absorbing states.

The harmonic function is denoted by f, with component f(i) corresponding to state i.
