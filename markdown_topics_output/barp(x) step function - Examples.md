# Examples
If $p(j)=\frac12$ for $j=0$ and $j=1$ and $0$ otherwise, then $\bar{p}(x)=\frac12$ on $[-\tfrac12,\tfrac12)$ and on $[\tfrac12,\tfrac32)$, and $0$ elsewhere.

The step function $\bar{p}_n(x)$ is obtained by applying the same construction to the $n$‑fold sum distribution $p_n$, and $\bar{p}_n^{*}(x)$ to its standardized version $p_n^{*}$.
