# Notation
a – the number of packets into which the deck may be cut; n – number of cards; M=(m_1,…,m_n) – an element of S, the set of n‑tuples with entries in {0,…,a-1}; n_i – the number of entries of M equal to i; S – the set of all such n‑tuples; the a‑shuffle associated to M – the permutation defined by the labeling and placement procedure described above; r – a possible number of rising sequences in the resulting permutation; A(n,r) – the Eulerian number counting permutations of n with exactly r rising sequences.
