# Proof
The proof presented uses Chebyshev’s Inequality to bound $P(|S_n/n-mu|ge epsilon)le sigma^2/(nepsilon^2)$ and shows this tends to zero as $n$ grows.  No proof is provided for the Strong Law of Large Numbers in this text.

A standard proof uses Chebyshev's inequality together with the Borel–Cantelli lemma, showing that the events |S_n/n - μ| > ε occur only finitely many times with probability one.

The proof provided in the text uses the fact that for independent variables with bounded variances, the probability that |S_n/n - M_n/n| < ε tends to one, and then applies a convergence argument to obtain almost sure convergence.
