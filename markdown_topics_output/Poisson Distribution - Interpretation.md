# Interpretation
The parameter \(\lambda\) represents the average number of events expected in the specified interval. For the bomb‑hit example, \(\lambda=537/576\) is the mean hits per square; for traffic, \(m\) and \(\overline m\) are the mean arrivals from each direction. The Poisson model therefore gives the probability of observing any particular count given that mean.

The additive property shows that independent sources of Poisson events combine without changing the distributional form, reflecting the idea that rare events from different origins simply add together.
