# Statement
For a regular transition matrix P the limit W = lim_{n→∞}P^n exists and every row of W is identical; denote that common row by w.  The vector w satisfies wP = w, and any row vector v with vP = v is a scalar multiple of w.  Moreover, Pc = c where c is the all‑ones column vector, and any column vector x with Px = x is a scalar multiple of c.
