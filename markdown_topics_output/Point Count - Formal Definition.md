# Formal Definition
Let a random variable $X$ represent the value assigned to a single randomly dealt card: $P(X=0)=36/52$, $P(X=1)=4/52$, $P(X=2)=4/52$, $P(X=3)=4/52$, $P(X=4)=4/52$. For a hand of 13 cards, define $C=sum_{i=1}^{13}X_i$ where the $X_i$ are independent copies of $X$. The point count $C$ is the random variable representing this sum, whose distribution is obtained by convolving the single‑card distribution $p_X$ 13 times.
