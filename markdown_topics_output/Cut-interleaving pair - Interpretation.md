# Interpretation
Each cut‑interleaving pair uniquely determines a permutation of the deck when applied to the identity ordering, but different pairs may produce the same permutation. The probability assigned to a permutation by an a‑shuffle is proportional to the number of cut‑interleaving pairs that yield that permutation. Theorem 3.10 shows that composing an a‑shuffle with a b‑shuffle is probabilistically equivalent to a single ab‑shuffle because the sets S_{a,b} and S_{ab} are in bijection and map to the same permutations with the same multiplicities.
