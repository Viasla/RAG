# Properties
1. α(p) decreases as the critical value m increases, reducing the type 1 error. 2. β(p)=1−α(p) increases as m increases, thereby increasing the type 2 error. 3. For a fixed n, there is a trade‑off: the critical value that minimizes α(p) for the null typically maximizes β(p) for plausible alternative values of p, and vice versa. 4. If the alternative probability is close to the null probability (e.g., p=0.61 versus p=0.6), β(p) rises sharply for a given n, requiring a larger sample size to maintain a low type 2 error. 5. In the example with n=100, a critical value m between 69 and 73 achieves both α(.6)<0.05 and β(.8)<0.05. 6. The choice of m can be guided by the relative cost or consequence of each error type; the text suggests using 73 to guard against type 1 error or 69 if type 2 error is considered worse.
