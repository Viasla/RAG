# Statement
The expected number of steps before absorption, starting from a transient state $s_i$, is denoted $t_i$.  The vector $mathbf{t}$ collects these expectations, with the $i$th entry equal to $t_i$.  For an absorbing Markov chain with fundamental matrix $mathbf{N}=(I-mathbf{Q})^{-1}$ and column vector $mathbf{c}$ whose entries are all one, the relationship $mathbf{t}=mathbf{N}mathbf{c}$ holds.

Theorem 11.5 states that if $mathbf{t}$ is the column vector of expected absorption times $t_i$ and $mathbf{c}$ is a column vector of ones, then $mathbf{t}=mathbf{N}mathbf{c}$, where $mathbf{N}=(I-mathbf{Q})^{-1}$ is the fundamental matrix of the chain.
