# Examples
For the set A={a,b,c}, the permutation σ given by σ=(a→b, b→c, c→a) is a 3‑permutation of A.

The list of all permutations of the numbers {1,2,3}, namely 123, 132, 213, 231, 312, 321, is a 3‑permutation of the set {1,2,3}.

When k=n, a k‑permutation coincides with a full permutation of the set.
