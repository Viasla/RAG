# Examples
Using the Poisson approximation, the probability that a particular 24 × 24 square in London receives exactly \(k\) bomb hits is \(P\{X=k\}=e^{-\lambda}\lambda^{k}/k!\) with \(\lambda=537/576\) (the average hits per square). The expected number of squares with 0, 1, 2, 3, 4, and 5 or more hits is then 576 times the corresponding probabilities, which can be compared with the observed counts 229, 211, 93, 35, 7, 1.

If the number of cars arriving from the north in a unit time interval follows \(\text{Poisson}(m)\) and the number arriving from the west follows \(\text{Poisson}(\overline m)\) independently, the total number of cars \(X+Y\) is \(\text{Poisson}(m+\overline m)\).

At a road fork where the total arrival process is \(\text{Poisson}(\lambda=4)\) and each car independently chooses Main Street with probability 3/4, the count of cars on Main Street is \(\text{Poisson}(\lambda=4\times3/4=3)\).
