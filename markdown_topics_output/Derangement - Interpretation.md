# Interpretation
In probability terms, p_n is the chance that a random permutation has no fixed points; as n grows, p_n approaches 1/e≈0.368, showing that about 36.8 % of large random shuffles are derangements.

The hat‑check problem asks for exactly this probability, and de Montmort’s recursion computes the count w_n that underlies the probability.

The inclusion‑exclusion principle provides an alternative derivation of w_n by alternatingly adding and subtracting the counts of permutations that fix a given set of positions.
