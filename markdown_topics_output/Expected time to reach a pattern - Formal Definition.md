# Formal Definition
Let B be a fixed finite string of H's and T's. Define T^B as the random variable giving the number of coin tosses required for B to appear for the first time in an infinite sequence of independent fair coin tosses. Then the expected time to reach the pattern is E(T^B).

If A is another pattern that does not contain B as a subpattern, define E_A(T^B) as the expected additional number of tosses needed to see B when the process already ends with the pattern A. The formula derived from the fair‑game argument is E_A(T^B)=BB-AB, where BB and AB are the total winnings associated with the patterns B and the pair (A,B).
