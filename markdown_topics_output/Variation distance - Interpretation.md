# Interpretation
The variation distance ranges from 0 to 1; a value of 0 means the process X is exactly random (its distribution matches the uniform distribution), while a value of 1 indicates maximal deviation from randomness. Multiplying the raw sum of absolute differences by 1/2 normalises the measure because the unscaled sum attains a maximum of 2.

For any event T\subset S_n, the absolute difference |P_X(T)-P_U(T)| is bounded above by the variation distance. The event that attains the maximum difference is the one that best distinguishes the two processes; thus the variation distance is the worst‑case probability gap between X and a truly random shuffle.
