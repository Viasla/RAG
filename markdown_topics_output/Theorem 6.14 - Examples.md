# Examples
In Example 6.27 the normal random variable X with parameters μ and σ is written as X = σZ + μ, where Z is standard normal. Applying Theorem 6.14 together with Theorem 6.10 yields V(X) = V(σZ + μ) = σ^2 V(Z) = σ^2, because V(Z) = 1.

Theorem 6.14 is also implicitly used when computing the variance of the exponential distribution in Example 6.26, where the variance V(X) is obtained as 1/λ^2 after evaluating the integral.
