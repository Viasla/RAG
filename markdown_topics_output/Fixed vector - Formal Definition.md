# Formal Definition
A row vector w satisfying wP = w is called a fixed row vector for the transition matrix P; similarly, a column vector x satisfying Px = x is called a fixed column vector for P.

A fixed vector w for a transition matrix P is a probability row vector satisfying wP = w, with all components w_i ≥ 0 and ∑_i w_i = 1. In other words, w is a left eigenvector of P associated with eigenvalue 1 that is normalized to be a probability distribution.
