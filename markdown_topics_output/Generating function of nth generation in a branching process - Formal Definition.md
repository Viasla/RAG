# Formal Definition
For a branching process with one‑step offspring generating function h(z)=\sum_{k\ge0}p_k z^k, the nth‑generation generating function is defined recursively by h_1(z)=h(z) and h_{n+1}(z)=h_n\bigl(h(z)\bigr) for n\ge1.

Equivalently, h_n(z)=h\bigl(h\bigl(\dots h(z)\dots\bigr)\bigr) with h applied n times, so that h_n(z)=h^{\circ n}(z).
