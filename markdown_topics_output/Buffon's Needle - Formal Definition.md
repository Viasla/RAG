# Formal Definition
Let the distance between adjacent parallel lines be W and let the needle length satisfy 0 < L ≤ W. Choose independently a distance d ∈ [0, W/2] uniformly and an angle θ ∈ [0, π/2] uniformly. Define the event E = {d ≤ (L/2) sin θ}. Then the probability of a crossing is P(E) = (2L)/(πW).

If L > W the formula generalises to P(E) = (2/π)(L/W) – (1/π)(L/W)√{(L/W)² – 1} + (2/π)arcsin(W/L).
