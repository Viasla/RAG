# Notation
L – length of the needle (or bread loaf).

W – spacing between parallel lines (or width of floorboards).

d – perpendicular distance from the needle’s centre to the nearest line, 0 ≤ d ≤ W/2.

θ – acute angle between the needle and the lines, 0 ≤ θ ≤ π/2.

E – event that the needle crosses a line.

P(E) – probability of the crossing event.

π – the mathematical constant, appearing in the analytical expression for P(E).
