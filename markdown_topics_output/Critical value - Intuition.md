# Intuition
The critical value is the threshold number of successful outcomes in an experiment that determines whether the null hypothesis is rejected. It represents a balance point where the probabilities of committing type 1 and type 2 errors are both minimized; choosing a value too high will reduce type 1 errors but increase type 2 errors, whereas choosing it too low will have the opposite effect. In practice it is chosen so that the likelihood of each error is kept below a pre‑set significance level, such as 5 %.

In the aspirin example, setting the critical value to 69 out of 100 participants gives a type‑1 error probability below 5 %, while 73 gives a type‑2 error probability below 5 %. The decision is made based on whether the researcher prioritises avoiding false positives or false negatives.
