# Properties
The Cauchy density is symmetric about zero and is defined for all real x; its mean does not exist, so the Law of Large Numbers does not apply to averages of Cauchy‑distributed random variables, as noted in the text.

The Cauchy density is stable: any linear combination $aX+bY$ (with $X,Y$ independent Cauchy) has the same functional form up to location and scale parameters.

All moments of order $\ge 2$ are infinite; in particular $\mu_2=\infty$.

Its characteristic function is $k_X(\tau)=e^{-|\tau|}$, which is a real‑valued, even function decaying exponentially in $|\tau|$.

The sample average of i.i.d. Cauchy variables has the same distribution as each individual observation, demonstrating failure of the Law of Large Numbers for this distribution.
