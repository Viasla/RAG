# Proof
Let H_i denote the event that the i‑th toss is a head, and let F_k denote the event that exactly k heads occur in the n trials.  Because the tosses are i.i.d., the number of sequences in which the i‑th position is a head and exactly k heads occur is •C(n−1,k−1).  The total number of sequences in F_k is C(n,k).  Therefore 
P(H_i|F_k)=C(n−1,k−1)/C(n,k)=k/n.
