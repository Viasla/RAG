# Properties
For any pattern B, the expected waiting time satisfies E(T^B)=BB, where BB is computed by the gambling scheme as the sum of the winnings of the last |B| gamblers who win when B occurs.

If the process starts with a prefix A that does not already contain B, then E_A(T^B)=BB-AB, showing a linear relationship between the expected waiting time from different starting states.

For any integer‑valued non‑negative random variable T, the identity E(T)=\sum_{n=0}^{\infty}P(T>n) holds; applying this to pattern‑waiting times yields the same results as the gambling and Markov‑chain arguments.

The Markov‑chain absorption time can be computed by solving a system of linear equations (or using the fundamental matrix) for the transient states; the solution coincides with the BB values derived from the gambling interpretation.
