# Examples
Example 4.10 defines X1,X2,X3 as the results of three fair‑coin tosses; the joint distribution of ̅X assigns probability 1/8 to each of the eight ordered triples (H,T,H) etc.

Example 4.11 extends the same experiment to Y_i, the number of heads in the first i tosses, and shows that the joint distribution of ̅Y assigns probability 1/8 to the eight admissible triples satisfying a1≤a2≤a3 and probability 0 to the 16 inadmissible triples such as (1,0,1).

Example 4.13 uses a real data set of 60 people to construct the joint distribution of the binary variables C (cancer) and S (smoking); the table lists P(C=0,S=0)=40/60, P(C=0,S=1)=10/60, etc., illustrating a joint distribution that is not a product of the marginals.
