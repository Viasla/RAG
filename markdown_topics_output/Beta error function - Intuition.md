# Intuition
The beta error function, β(p), measures how likely it is that a statistical test will miss a true effect when the alternative hypothesis is true.  For a fixed sample size n and critical value m, β(p) is large when the threshold m is set too high relative to the true success probability p, because many successes fall below the threshold and the test erroneously accepts the null hypothesis.  Conversely, lowering m reduces β(p) but increases the risk of a type 1 error (captured by α).  Thus β(p) represents the trade‑off between sensitivity and specificity in a hypothesis test.
