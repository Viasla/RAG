# Intuition
Regularity guarantees that, after some finite power, every entry of $\mathbf{P}^{k}$ is strictly positive, which means each state can reach every other state in a uniformly positive number of steps. This mixing property forces the distribution of the chain to become independent of its initial state as time grows. The lemma shows that each multiplication by $\mathbf{P}$ shrinks the spread of values in any vector; iteratively applying this shrinks the spread to zero, giving the same value in every component. This value is the stationary probability vector $\mathbf{w}$, and the limit matrix $\mathbf{W}$ is the outer product of a vector of all ones and $\mathbf{w}$.

For a regular Markov chain all entries of a sufficiently high power of its transition matrix are strictly positive, so each iteration of the chain mixes the components of the state vector.  The sequences of componentwise minima $m_n$ and maxima $M_n$ bound every component of $P^n y$ and converge to a common limit because the difference $M_n-m_n$ is multiplied each step by a factor $(1-2d)$ strictly less than 1, where $d>0$ is the smallest positive entry of $P$.  Intuitively the chain forgets its starting state exponentially fast and all rows of $P^n$ collapse to a single distribution vector $w$ with all entries strictly positive.
