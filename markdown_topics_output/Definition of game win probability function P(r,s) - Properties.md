# Properties
Recurrence: for 0\le r,s<N, P(r,s)=p\,P(r+1,s)+q\,P(r,s+1).

Boundary conditions: P(N,s)=1 for any s<N and P(r,N)=0 for any r<N.

Monotonicity: P(r+1,s)\ge P(r,s) and P(r,s+1)\le P(r,s).

Symmetry when p=1/2: P(r,s)=1-P(s,r).

Linearity: P(r,s) can be expressed as a finite sum of binomial terms based on remaining points needed.
