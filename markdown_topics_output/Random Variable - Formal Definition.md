# Formal Definition
For an experiment with possible outcomes \omega_1,\ldots,\omega_n, a random variable X assigns to each outcome a numerical value; the distribution function m(\omega) gives the probability of each outcome, satisfying m(\omega_1)+\cdots+m(\omega_n)=1.

A random variable can also be a function of several independent trials, such as X_1+X_2+X_3+X_4 where each X_i is the result of a separate die roll.

Definition 1.1 states that a random variable X is a capital Roman letter representing the outcome of an experiment.  The sample space Ω is the set of all possible outcomes, and the random variable is called discrete if Ω is finite or countably infinite.  Definition 1.2 introduces a distribution function m defined on Ω, satisfying m(ω) ≥ 0 for all ω ∈ Ω and ∑_{ω∈Ω} m(ω)=1.  For any event E⊆Ω, the probability of E is given by P(E)=∑_{ω∈E} m(ω).
