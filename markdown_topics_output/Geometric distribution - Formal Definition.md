# Formal Definition
Let 0<p<1 and q=1-p. The random variable T has a geometric distribution with parameter p if P(T=j)=q^{j-1}p for all integers j≥1.

Let p∈(0,1) be the probability of success in a Bernoulli trial.

Define T to be the number of independent Bernoulli trials needed to achieve the first success.

The probability mass function is P(T=k)=p q^{k-1} for k=1,2,… where q=1-p.

The expectation is E(T)=1/p.

The second moment is E(T^2)= (1+q)/p^2.

Thus the variance is V(T)=E(T^2)-(E(T))^2 = q/p^2.
