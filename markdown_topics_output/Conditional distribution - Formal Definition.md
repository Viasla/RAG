# Formal Definition
Let (Ω,𝔽,P) be a probability space and let E∈𝔽 with P(E)>0.  The conditional distribution of a random variable (or of the elementary outcomes) given E is the function m_E:Ω→[0,1] defined by m_E(ω)=P(\{ω\}\mid E)=P(\{ω\}\cap E)/P(E).  In notation this is often written P(·\mid E).
