# Intuition
The mean first passage time $m_{ij}$ is the expected number of steps a Markov chain, started in state $s_i$, will take before it visits state $s_j$ for the first time.  In an absorbing‑chain formulation the quantity equals the expected number of steps required to reach the absorbing state $s_j$ when the chain is started at $s_i$.

In the maze example the rat moves randomly among compartments until it reaches the food placed at compartment 5; the mean first passage time from a given compartment to the food is the average number of moves the rat will need before it first finds the food.

Mean first passage time quantifies the average number of steps a Markov chain must take before it visits a specified state for the first time, i.e., the expected waiting time between successive visits to that state when the chain starts from a given initial state.
