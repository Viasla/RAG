# Notation
H₀ denotes the null hypothesis; α(p) is defined as the probability of rejecting H₀ when it is true, i.e., the type‑1 error rate. For the aspirin example, α(.6) is the upper‑tail probability of a binomial distribution with parameters n and p = 0.6. β(p) = 1 − α(p) gives the probability of a type‑2 error when the true p differs from the null value. The binomial probability mass function is denoted b(n, p, k).
