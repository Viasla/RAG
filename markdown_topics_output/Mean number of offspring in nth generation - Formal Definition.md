# Formal Definition
Let $h(z)=\sum_{k=0}^\infty p_k z^k$ be the probability generating function of the number of offspring produced by a single parent. The mean number of offspring per parent is $m=h'(1)=\sum_{k=0}^\infty k p_k$. The mean number of offspring in the $n$th generation is denoted $m_n$ and satisfies $m_{n+1}=m_n\cdot m$, with $m_1=m$. Solving the recurrence gives $m_n=m^n$ for all $n\ge1$.
