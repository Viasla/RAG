# Examples
Example 8.3 calculates the bound for n=100 giving P(|A_100−0.3|≥0.1)≤0.21, and for n=1000 giving P(|A_1000−0.3|≥0.1)≤0.021.

Consequently, P(0.2<A_100<0.4)≥0.79 and P(0.2<A_1000<0.4)≥0.979, which are compared with actual probabilities approximately 0.962549 and 1 respectively.

Exercise 6 provides a general application, showing that for any ε>0, the inequality gives P(|S_n/n−p|≥ε)≤p(1−p)/(nε^2).

Exercise 7 uses the fact that p(1−p)≤1/4 to produce the simplified bound P(|S_n/n−p|≥ε)≤1/(4nε^2) valid for all p.
