# Notation
$p_k$ – probability that a parent produces $k$ offspring; $h(z)=\sum_{k\ge0}p_k z^k$ – generating function; $m=h'(1)=\sum k p_k$ – mean offspring per parent; $m_n$ – mean number of offspring in the $n$th generation; $Z_n$ – random variable for the number of offspring in generation $n$; $h_n(z)$ – generating function of $Z_n$.
