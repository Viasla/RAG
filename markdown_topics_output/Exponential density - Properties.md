# Properties
The cumulative distribution function is F(x)=1−e^{−λ x} for x≥0.

The exponential density satisfies the memoryless property: P(T>r+s | T>r)=P(T>s)=e^{−λ s}.

The sum S_n = X_1+…+X_n of n independent exponential(λ) variables has a gamma density g_n(x)=λ (λ x)^{n−1}/(n−1)! e^{−λ x}.

The probability that a Poisson(λ t) random variable equals n is P(Y=n)=e^{−λ t}(λ t)^n/n!, which follows from the exponential inter‑arrival times.

The exponential density is a special case of the gamma density with shape parameter n=1.
