# Proof
Exercise 17(c) derives the variance addition formula by expanding the definition of variance (displaystyle V(X+Y)=E[(X+Y)^2]-[E(X+Y)]^2).  After algebraic manipulation this expression becomes (displaystyle V(X)+V(Y)+2,E[(X-mu(X))(Y-mu(Y))]), where the last term is exactly the covariance (operatorname{cov}(X,Y)).  Part (b) of the same exercise shows that if (X) and (Y) are independent, then (operatorname{cov}(X,Y)=0) because (E[(X-mu(X))(Y-mu(Y))]=E[X-mu(X)],E[Y-mu(Y)]=0), yielding the simplified additive result.
