# Intuition
If each summand X_i contributes a factor f(z)=E(z^{X_i}) to the overall generating function, then conditioning on the random count N simply raises this factor to the N‑th power; averaging over N replaces the power by the generating function g of N, yielding the composition g∘f.

In a branching process, one generation’s offspring distribution is described by f(z); applying f again corresponds to two generations, which is why the two‑step generating function is f(f(z)).
