# Examples
In a queuing system where customers arrive independently in each discrete time unit with probability p, the waiting time T until the next arrival has a geometric distribution; the probability that no arrival occurs in the next k time units is P(T>k)=q^k.

The random variable Y defined by the smallest integer satisfying 1−q^Y≥rnd (with rnd uniformly distributed on [0,1)) has the same distribution as T, and can be generated by Y=⌈log(1−rnd)/log q⌉.

For a fair coin (p=1/2) the variance of T is (1/2)/(1/2)^2 = 2.

For a die with a six having probability 1/6 (p=1/6) the variance of T is (5/6)/(1/6)^2 = 30.

These examples illustrate the rapid increase of variance as p decreases.
