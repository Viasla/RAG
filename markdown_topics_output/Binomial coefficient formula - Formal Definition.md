# Formal Definition
The binomial coefficient is defined by the formula $displaystyle inom{n}{r} = rac{(n)_r}{r!}$, where $(n)_r=n(n-1)(n-2)dots(n-r+1)$ denotes the falling factorial.

An equivalent expression is $displaystyle inom{n}{r}=rac{n!}{r!,(n-r)!}$.  The same formula appears in the text as the rule equivalent to our binomial coefficient definition.
