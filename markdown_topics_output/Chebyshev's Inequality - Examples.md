# Examples
Example 8.3: For a Bernoulli process with success probability 0.3, Chebyshev’s inequality gives P(|A_{100}‑0.3|≥0.1)≤0.21 and P(|A_{1000}‑0.3|≥0.1)≤0.021, which translate to lower bounds P(0.2<A_{100}<0.4)≥0.79 and P(0.2<A_{1000}<0.4)≥0.979.

Exercise 1: For 100 fair‑coin tosses (p=0.5, variance 0.25), Chebyshev’s inequality yields P(|#heads‑50|≥15)≤0.25·100/(15²)=100/900≈0.111, i.e., the probability of deviating by three standard deviations is at most about 11%.

Exercise 6: For S_n the number of successes in n Bernoulli trials with probability p, Chebyshev’s inequality gives P(|S_n/n‑p|≥ε)≤p(1‑p)/(nε²).

Exercise 7: Using the fact that the maximum of p(1‑p) over 0<p<1 is 1/4, we obtain the universal bound P(|S_n/n‑p|≥ε)≤1/(4nε²).

The exercise explicitly lists the probability estimations to be performed: 
• (P(499,500 le S le 500,500))
• (P(499,000 le S le 501,000))
• (P(498,500 le S le 501,500))
These are to be calculated with Chebyshev's inequality and with the Central Limit Theorem.
