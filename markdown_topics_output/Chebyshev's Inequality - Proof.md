# Proof
Starting from Markov’s inequality applied to the non‑negative random variable (X‑E(X))², we have P((X‑E(X))²≥ε²)≤E[(X‑E(X))²]/ε² = V(X)/ε², which is exactly Chebyshev’s inequality.

In Example 8.3 the variance of the sample average is computed as V(A_n)=V(S_n)/n²=0.21/n; substituting ε=0.1 yields the concrete bound P(|A_n‑0.3|≥0.1)≤0.21/(n·0.01)=21/n.
