# Notation
\(X\): a process producing an ordering of {1,…,n}; \(f_X(\pi)\): probability that X produces ordering \(\pi\); \(\Omega_n\): set of all n! orderings; \(u(\pi)=1/|\Omega_n|\): uniform distribution; \(\|f_X-u\|\): variation distance; \(A(n,r)\): Eulerian number; \(\binom{2^s+n-r}{n}\): combinatorial term counting cut‑interleaving pairs for r rising sequences; \(s\): number of riffle shuffles.

The variation distance is denoted by \|f_X-u\| or sometimes by d_{TV}(f_X,u). The two distributions are f_X(\pi) for the shuffling process X and u(\pi)=1/n! for the uniform process on S_n.
