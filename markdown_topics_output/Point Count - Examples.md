# Examples
Example 7.2 in the text shows the single‑card distribution table for the simplified point count. By treating the 13 cards as independent trials with this distribution, the program NFoldConvolution can compute the distribution of $C$. A player with $Cge 13$ is said to have an opening bid. Using this method, the probability of an opening bid is $P(Cge 13)=0.2845$, or about one in four hands.
