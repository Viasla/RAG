# Formal Definition
β(p) is defined as the probability of a type 2 error when the true success probability is p.  In the example, β(p) = 1 – α(p), where α(p) = \sum_{k=m}^{n} b(n,p,k), and b(n,p,k) is the binomial probability mass function.  Hence, for each alternative value of p, β(p) gives the chance that the number of successes will be fewer than the critical value m, so that the null hypothesis is mistakenly retained.
