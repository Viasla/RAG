# Examples
The time between successive emissions of particles from a radioactive source is modeled by an exponential density.

In a single‑server queue, the inter‑arrival times X_i and service times Y_i are often assumed to be exponentially distributed with parameters λ and μ respectively.

A computer can simulate an exponential random variable by computing Y = −(1/λ)·log(rnd), where rnd is a uniform(0,1) variate.
