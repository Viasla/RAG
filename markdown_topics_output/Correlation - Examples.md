# Examples
For independent random variables X and Y uniformly distributed on [0,1], Exercise 19(a) yields ρ(X,Y)=0, illustrating that independence implies zero correlation.

In the bivariate standard normal density f_{X,Y}(x,y)=\frac{1}{2π\sqrt{1-ρ^2}}\exp\{-\frac{x^2-2ρxy+y^2}{2(1-ρ^2)}\}, part (b) of Exercise 20 shows that the parameter ρ appearing in the exponent is exactly the correlation coefficient of X and Y.

The sample correlation estimator \bar r=\frac{\sum_i (x_i-\bar x)(y_i-\bar y)}{(n-1)s_X s_Y} (Exercise 25) provides a practical way to compute an empirical correlation from paired data such as Galton’s father‑son height measurements.
