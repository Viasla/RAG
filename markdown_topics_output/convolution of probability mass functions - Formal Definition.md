# Formal Definition
For independent discrete random variables $X$ and $Y$ with pmfs $p_X$ and $p_Y$, the convolution $p_Z=p_X* p_Y$ is defined by $p_Z(j)=\sum_{i\in\mathbb Z} p_X(i)\,p_Y(j-i)$, where the sum ranges over all integers $i$ for which both $p_X(i)$ and $p_Y(j-i)$ are defined. This definition captures the distribution of the sum $Z=X+Y$.
