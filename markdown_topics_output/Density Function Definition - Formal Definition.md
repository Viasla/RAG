# Formal Definition
Let X be a continuous real‑valued random variable. A function f:\mathbb{R}\to[0,\infty) is called a density function for X if for every a,b\in\mathbb{R} with a\le b we have P(a\le X\le b)=\int_{a}^{b}f(x)\,dx.

Equivalently, for any measurable subset E\subset\mathbb{R} for which the integral makes sense, P(X\in E)=\int_{E}f(x)\,dx.
