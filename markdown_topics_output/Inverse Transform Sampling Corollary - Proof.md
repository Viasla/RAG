# Proof
Because $U$ has cumulative distribution function $F_U(u)=u$, for any $y$ we have 
$$P(Yle y)=P(F^{-1}(U)le y)=P(Ule F(y))=F_U(F(y))=F(y),$$ 
which shows that $Y$ has CDF $F$. This follows directly from Theorem 5.1 and the uniqueness of the solution of $F(y)=u$ when $F$ is strictly increasing.
