# Proof
Theorem 5.1 follows from the change‑of‑variables formula for cumulative probabilities: P(X≤x)=P(φ(Z)≤x)=P(Z≤φ⁻¹(x))=F_Z(φ⁻¹(x)). Differentiating this relation with respect to x, using the chain rule and the fact that φ is monotone so the absolute value of the derivative of its inverse is 1/|φ′(φ⁻¹(x))|, yields f_X(x)=f_Z(φ⁻¹(x))⋅|d/dx φ⁻¹(x)|.  In the case of the linear map φ(z)=σz+µ, φ′(z)=σ>0 and d/dx φ⁻¹(x)=1/σ, giving f_X(x)=f_Z((x‑µ)/σ)·(1/σ).
