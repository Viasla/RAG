# Formal Definition
Definition 6.1 states that for a numerically‑valued discrete random variable $X$ with sample space $\Omega$ and distribution function $m(x)$, the expected value is $E(X)=\sum_{x\in\Omega} x\,m(x)$, provided the series converges absolutely; if it does not converge, $X$ is said to have no expected value.

The expected value of a discrete random situation is the sum of each possible payoff multiplied by its probability, e.g., $p(-u)+(1-p)v$ for the belief strategy in Pascal’s wager, and similarly $p\cdot0+(1-p)(-x)$ for the non‑belief strategy.

In the dice game described by Huygens, letting $x$ be the chance of winning when the opponent throws first and $y$ when Huygens throws first leads to the system $x=\frac{31}{36}y$ and $y=\frac{6}{36}+\frac{30}{36}x$, whose solution $x=31/61$ is the expected probability of Huygens winning.

The expected value of a life annuity is the expected value of a terminal annuity evaluated over the random lifetime of the buyer, linking mortality tables to financial pricing.

For a discrete random variable $X$ with possible values $a_1,\dots,a_r$ and probabilities $p_1,\dots,p_r$, the expected value is $E(X)=\sum_{i=1}^r a_i p_i$. For a continuous random variable with density $f(x)$, the expected value is $\mu = E(X)=\int_{-\infty}^{+\infty} x f(x)\,dx$, provided $\int_{-\infty}^{+\infty} |x| f(x)\,dx$ is finite.
