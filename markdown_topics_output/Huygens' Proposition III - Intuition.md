# Intuition
The intuition behind Prop. III is that a fair game’s value is proportional to how often each outcome appears; if outcome a occurs p times out of p+q equally likely elementary events and outcome b occurs q times, then the average payoff per event is (p·a + q·b)/(p+q). Thus the expected value is simply the weighted average of the two possible winnings, with weights proportional to the number of favourable elementary events for each outcome.
