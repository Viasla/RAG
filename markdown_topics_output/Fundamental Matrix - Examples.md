# Examples
In the preceding section the fundamental matrix $N$ for an absorbing version of the maze problem was computed explicitly as $N=\frac{1}{8}\begin{pmatrix}14&9&\dots\end{pmatrix}$, illustrating how a fundamental matrix yields expected numbers of visits and absorption times. Although the ergodic fundamental matrix $Z$ is not numerically displayed, the same maze chain is used to motivate the need for a new matrix when the absorbing state is removed.

Exercise 1 asks to find the fundamental matrix Z for the chain with transition matrix [[1/2,1/2],[1/4,3/4]] and then compute the mean first passage matrix using Z.

Exercise 6 asks to make rain an absorbing state in the Land of Oz example and find the fundamental matrix N, interpreting the results.

Exercise 7(d) involves using the fundamental matrix to find the expected number of steps before reaching Room 5 for the first time.
