# Properties
Recurrence: $m_{n+1}=m_n\,m$; Closed form: $m_n=m^n$; Monotonicity: if $m>1$, $m_n$ is strictly increasing; if $0\le m<1$, $m_n$ is strictly decreasing; Fixed point: $m=1$ yields $m_n=1$ for all $n$; Relation to extinction: if $m\le1$, extinction probability $d=1$; if $m>1$, extinction probability $d<1$ and $m_n$ still follows $m^n$ regardless of $d$.
