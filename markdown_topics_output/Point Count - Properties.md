# Properties
1. The point count $C$ is the sum of 13 independent, identically distributed integer‑valued random variables with common pmf $p_X$. 2. The distribution of $C$ can be obtained via 13‑fold convolution of $p_X$. 3. The event ${Cge13}$ corresponds to an opening bid and has probability $0.2845$ under the simplified model. 4. The simplified point count ignores suit voids and other advanced hand evaluation features, which in practice would alter the distribution. 5. The method exemplifies the use of convolution for sums of discrete random variables.
