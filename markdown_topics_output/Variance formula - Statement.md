# Statement
Definition: For a real‑valued random variable X with mean μ=E(X), the variance is defined by V(X)=E[(X-μ)^2].

Alternative integral form: V(X)=∫_{-∞}^{∞} (x-μ)^2 f(x) dx.

Variance of a scaled variable: For any constant c, V(cX)=c^2 V(X).

Variance of a shifted variable: V(X+c)=V(X).

Additivity for independent variables: If X and Y are independent, V(X+Y)=V(X)+V(Y).

Formula via second moment: V(X)=E(X^2)-μ^2.
