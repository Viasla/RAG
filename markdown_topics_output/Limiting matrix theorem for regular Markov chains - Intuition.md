# Intuition
Theorem 11.7 relies on the observation that each application of the transition matrix to a vector performs an averaging operation on the vector’s components.  Repeated averaging drives the maximum component down and the minimum component up, so the difference between the largest and smallest entries of µ_n=µP^n decreases to zero.  Consequently the sequence of vectors P^nµ converges to a constant vector for every initial vector µ, which forces every row of P^n to become identical as n grows.
