# Formal Definition
If Ω denotes the universal or sample space and A is a subset of Ω, the complement of A, usually written ˘A or A^c, is defined by ˘A = \{x \mid x \in \u03A9 \text{ and } x \not\in A\}.

In the text this definition is presented as \tilde{A} = \{x | x \in \Omega \text{ and } x \notin A\}.

It is the set of all outcomes in the sample space that are not elements of A.
