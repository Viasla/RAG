# Notation
D – a particular ordering of the deck; a, b – positive integers denoting the number of stacks in each shuffle; ab – the product of a and b; S_a – the set of all a‑shuffle cut‑interleaving pairs; S_{a,b} – the set of cut‑interleaving pairs obtained by first an a‑shuffle then a b‑shuffle; S_{ab} – the set of cut‑interleaving pairs for a single ab‑shuffle; n – the number of cards in the deck; m_1, m_2 – counts of elements of S_{a,b} and S_{ab} that produce a given ordering D.
