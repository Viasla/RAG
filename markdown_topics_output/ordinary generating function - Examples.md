# Examples
If the moments of X satisfy \mu_0=1 and \mu_k=\frac12+\frac{2^{k}}{4} for k\ge1, then g(t)=\frac14+\frac12 e^{t}+\frac14 e^{2t}, so h(z)=\frac14+\frac12 z+\frac14 z^{2}, giving the distribution {0:1/4,1:1/2,2:1/4}.

For independent binomial variables X and Y with p_X(j)=p_Y(j)=\binom{n}{j}p^{j}q^{n-j}, the ordinary generating function is h_X(z)=h_Y(z)=(pz+q)^{n}, and for Z=X+Y we have h_Z(z)=(pz+q)^{2n}=\sum_{j=0}^{2n}\binom{2n}{j}p^{j}q^{2n-j}z^{j}, so p_Z(j)=\binom{2n}{j}p^{j}q^{2n-j}.

For independent geometric variables with p_X(j)=p_Y(j)=q^{j}p, the ordinary generating function is h_X(z)=h_Y(z)=\frac{p}{1-qz}, and for Z=X+Y we obtain h_Z(z)=\frac{p^{2}}{(1-qz)^{2}}=p^{2}\sum_{k=0}^{\infty}(k+1)q^{k}z^{k}, whose coefficients give the negative‑binomial distribution of Z.
