# Intuition
The variance quantifies the average squared deviation from the mean; multiplying a random variable by a constant stretches or compresses its values, so the squared deviations scale by the square of that constant. Because variance is a second‑order moment, it behaves like the square of a standard deviation, hence the factor of $c^2$ when scaling. Adding a constant merely shifts all outcomes and does not change spread, so the variance remains unchanged. When summing independent identically distributed random variables, each contributes additively to the spread, which is reflected by the linear increase of variance with the number of terms. The average reduces spread inversely with the number of observations, leading to a variance that decreases with $1/n$. These patterns illustrate how variance captures dispersion in a way that is sensitive to scaling but insensitive to location changes.

Variance measures the average squared deviation from the mean. If the variable is stretched by a factor c, each deviation from the mean is also stretched by c, and the squared deviations grow by c^2. Hence variance scales with the square of the linear scaling factor, while a translation (adding a constant) merely shifts the variable without affecting the spread, leaving variance unchanged.
