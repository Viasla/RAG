# Formal Definition
For a random variable X taking values in a finite set of outcomes {ω1, ω2, …, ωn}, a distribution function m is a mapping ωj ↦ m(ωj) where each m(ωj) is a nonnegative real number and the sum m(ω1)+m(ω2)+…+m(ωn)=1. The function m(ωj) represents the probability that X equals the corresponding outcome ωj. This definition ensures that the total probability over all outcomes equals one, and each individual probability is between 0 and 1.

Let X be a random variable that takes values in a finite or countably infinite sample space Ω. A distribution function for X is a real‑valued function m defined on Ω that satisfies two conditions: (i) m(ω) ≥ 0 for every ω ∈ Ω, and (ii) Σ_{ω∈Ω} m(ω) = 1. For any subset E ⊆ Ω, the probability of the event E is defined by P(E) = Σ_{ω∈E} m(ω).

The cumulative distribution function of a random variable X is defined by F(x)=P(X\le x).
