# Examples
In a dice roll, the event \(E=\{2,4,6\}\) corresponds to the statement that the result is an even number.

In two coin tosses, the event \(E=\{HH,HT,TH\}\) corresponds to “at least one head appears.”

The event \(F=\{HH,HT\}\) corresponds to “the first toss is heads.”

The term “event” is listed on page 18 of the source material.

The phrase “of an event” appears on page 19 in the context of probability concepts.
