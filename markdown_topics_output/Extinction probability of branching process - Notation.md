# Notation
$d_n$ denotes the probability that a branching process has died out by generation $n$; $d$ is the limiting extinction probability as $n	oinfty$. The offspring generating function $f(z)=sum_{j=0}^infty p_j z^j$ encodes the distribution ${p_j}$ of the number of offspring per individual. In the Poisson case the generating function simplifies to $f(z)=e^{m(z-1)}$, where $m$ is the mean number of offspring. The survival probability at generation $n$ is given by $1-d_n$.
