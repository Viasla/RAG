# Examples
Using the bound P(D\ge a)\le \sigma^2/(\mu^2 a^2) for the random variable X of Exercise 1, one can compute upper bounds for various thresholds: for a=0.2 the bound is \sigma^2/(\mu^2\cdot0.04); for a=0.5 the bound is \sigma^2/(\mu^2\cdot0.25); for a=0.9 the bound is \sigma^2/(\mu^2\cdot0.81); and for a=2 the bound is \sigma^2/(\mu^2\cdot4). The exercise asks the student to evaluate these expressions with the specific mean and variance from Exercise 1.
