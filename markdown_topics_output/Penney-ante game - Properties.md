# Properties
E(T^B)=BB, i.e., the expected waiting time for a pattern equals the total payoff a gambler would receive if the pattern were to occur.
E_A(T^B)=BB-AB, giving the expected additional waiting time when the process already matches pattern A.
Conway’s odds formula \(\frac{p_A}{p_B}=\frac{BB-BA}{AA-AB}\) holds for any pair of non‑overlapping patterns.
If both patterns have length k=2, the game is fair: p_A=p_B=1/2 for any choice of A and B.
For k=3 the second player always has an advantage; the optimal response to a first‑player pattern \(a_1a_2a_3\) is \(b\,a_1a_2\) where \(b\) is the opposite of \(a_3\) (the better of H or T).
More generally, for any k≥3 the optimal second‑player strategy is of the form \(b,a_1,…,a_{k-1}\), guaranteeing a higher win probability than the first player.
The game is non‑transitive: there exist triples of patterns where A beats B, B beats C, and C beats A.
All results rely on the assumption that neither pattern is a subpattern of the other, ensuring the Markov chain of suffixes is absorbing and the expectations are finite.
