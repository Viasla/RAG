# Notation
E(φ(X)) denotes the expected value of the transformed variable φ(X).

φ(x) is a continuous real‑valued function defined on [a,b].

f_X(x) is the probability density function of X.

The integral ∫_{−∞}^{+∞} φ(x) f_X(x) dx is taken over the entire real line, but the integrand is zero outside the support of f_X.
