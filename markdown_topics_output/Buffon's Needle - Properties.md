# Properties
The crossing probability is linear in the needle‑to‑line spacing ratio L/W when L ≤ W, making the estimator for π unbiased: π̂ = (2L)/(W·P̂(E)).

The variance of the estimator decreases as the number of drops N increases, with standard error proportional to 1/√N, so accuracy improves with larger samples.

If the needle length exceeds the line spacing, the probability formula becomes piecewise and involves arcsine terms, reflecting the additional ways a longer needle can intersect a line.

Uniform randomness in both centre position and orientation is essential; any bias in the distribution of d or θ will distort the estimated probability and hence the π estimate.
