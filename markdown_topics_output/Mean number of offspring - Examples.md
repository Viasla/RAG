# Examples
Example 1 (max two offspring): with probabilities p_0=.2, p_1=.5, p_2=.3, the mean number of offspring is m=.5+2\times .3=1.1, i.e., m=1-p_0+p_2=1-.2+.3=1.1.

Example 2 (geometric series): if p_k=b c^{k-1}, then m=\frac{b}{(1-c)^2}.

Example 3 (Japanese women data): Keyfitz’s analysis gave an expected number of female children per family of 1.837, which is the empirical mean m for that population.
