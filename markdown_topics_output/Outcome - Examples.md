# Examples
In Example 1.6 a die is rolled once: the outcomes are the numbers 1, 2, 3, 4, 5, 6.  In Example 1.7 a coin is tossed twice: the outcomes can be recorded as the ordered pairs HH, HT, TH, TT or as the number of heads 0, 1, 2.  In Example 1.9 three candidates A, B, C run for office: the outcomes are A, B, C.  In all cases each listed item is an outcome of the corresponding experiment.
