# Intuition
A random variable is a numerical expression whose value is the outcome of a particular experiment; it can assume different values depending on the result.

A random variable is a mathematical abstraction that encapsulates the result of an experiment; it allows us to quantify uncertainty by assigning probabilities to each possible outcome.  When the set of outcomes is finite or countably infinite, we say the random variable is discrete, which is the most common case considered in introductory probability.  The variable itself is not a number in every case (it may take values in a finite set like {A,B,C} or a set of integers), but it behaves like a function from the sample space to a set of values.

The term 'random variable' appears in the index on pages 1 and 18, implying it is treated as a fundamental notion of a numerical quantity that can vary according to a probability distribution.

The index lists various kinds of random variables—continuous (page 58), discrete (page 58), random integer (page 39), and random walk (page 471)—suggesting intuitive examples of objects that can assume multiple values stochastically.
