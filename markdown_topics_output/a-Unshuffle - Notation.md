# Notation
a – the number of piles used in the shuffle (e.g., a = 2 for a riffle shuffle).

n – the number of cards in the deck.

S – the set of all n‑tuples M = (m_1,…,m_n) with entries in {0,…,a‑1}.

M – a specific n‑tuple in S that encodes a particular a‑shuffle (and therefore its inverse a‑unshuffle).

n_i – the count of entries equal to i in M (the size of the i‑th pile).

σ – a permutation of the deck; the a‑unshuffle is the permutation that maps the shuffled order back to the identity ordering.
