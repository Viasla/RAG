# Notation
w denotes a fixed row vector (often the unique probability stationary distribution); x denotes a fixed column vector; c denotes the column vector of all ones; P denotes the transition matrix; wP = w and Px = x express the fixed‑vector property.

The fixed vector is commonly denoted by w, π, or sometimes by the symbol v; it is written as a row vector w = (w_1,w_2,…,w_n) or as a column vector when convenient, with the normalization ∑_i w_i = 1.
