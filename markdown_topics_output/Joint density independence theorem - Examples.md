# Examples
Example 4.22: For random variables X1 = ω1², X2 = ω2² defined on a uniform point (ω1, ω2) in the unit square, the joint cumulative distribution function F12(r1,r2) = √r1 √r2 equals the product F1(r1)F2(r2), and the joint density f12(x1,x2) factorises as f1(x1)f2(x2), confirming that X1 and X2 are independent.
