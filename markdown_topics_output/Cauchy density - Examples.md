# Examples
Example 5.11: a mirror is mounted one foot from an infinite straight wall; the incident angle φ is uniformly distributed on (−π/2,π/2); the reflected ray hits the wall at a point whose distance from the nearest point to the mirror axis is X; the derived density of X is the Cauchy density.

If $X$ and $Y$ are independent Cauchy random variables, then the sum $X+Y$ has characteristic function $k_{X+Y}(\tau)=e^{-2|\tau|}$, and the scaled sum $Z=(X+Y)/2$ has $k_Z(\tau)=e^{-|\tau|}$, showing that $Z$ has the same Cauchy density as $X$ and $Y$.

For an independent trials process $X_1,X_2,\dots,X_n$ with common Cauchy density, the sample average $A_n=\frac{1}{n}\sum_{i=1}^n X_i$ has exactly the same Cauchy density as each $X_i$.
