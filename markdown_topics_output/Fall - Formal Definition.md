# Formal Definition
Let \(\sigma\) be an ordering of \(\{1,2,\dots,n\}\). A **fall** occurs between positions \(i\) and \(i+1\) if the element at position \(i\) is larger than the element at position \(i+1\). For convenience we also declare that every ordering has a fall after the last position (i.e., after position \(n\)).
