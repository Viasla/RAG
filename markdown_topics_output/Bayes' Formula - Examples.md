# Examples
The integral formula P(a ≤ p < b | m successes in n trials) = (∫_a^b x^m(1‑x)^{n‑m} dx)/(∫_0^1 x^m(1‑x)^{n‑m} dx) serves as a concrete example of Bayes’ formula applied to estimating an unknown success probability.

This example demonstrates how Bayes’ rule transforms prior information (a uniform prior on p) into posterior probability using observed data.
