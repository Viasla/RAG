# Examples
In problem 52 a coin is hidden in one of n boxes.  After searching box i and not finding the coin, the posterior probability that the coin is in box j (j≠i) is p_j/(1‑a_i p_i); this is obtained by conditioning on the event “the search in box i failed”.

Problem 48 defines m_E(ω)=m(ω\mid E) and asks to verify that m_E is a distribution on E, i.e., non‑negative and summing to 1 – a direct illustration of the definition.

The Yankees–Dodgers series in problem 43 can be analysed by conditioning on the current score (r,s).  The probability P(r,s) of the Yankees eventually winning satisfies a recursion that is a conditional‑probability update after each game.

Problem 49 compares two urn strategies; the expected payoff of each strategy is computed by conditioning on which urn or which coin pair is selected.
