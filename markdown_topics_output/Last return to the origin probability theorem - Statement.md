# Statement
For a simple symmetric random walk of length 2m (m \ge 0), the probability that the walk’s last return to the origin occurs exactly at time 2k (where 0 \le k \le m) is

$$\frac{\binom{2k}{k}\binom{2m-2k}{m-k}}{2^{2m}} = u_{2k}\,u_{2m-2k},$$

where \(u_{2n}=\binom{2n}{n}/2^{2n}\) is the probability that a walk of length 2n returns to the origin at its final step.
