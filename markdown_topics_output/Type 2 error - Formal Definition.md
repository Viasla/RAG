# Formal Definition
The function α(p) is defined as the probability of rejecting the null hypothesis when the probability of success under the null is p. For a given sample size n and critical value m, 
α(p)=∑_{k=m}^{n}b(n,p,k), where b(n,p,k) is the binomial probability. The probability of a type 2 error when the true success probability is p>0.6 is then
β(p)=1−α(p). In the example, with p=0.8, β(0.8)=1−α(0.8) gives the probability of accepting the null when the additive is actually effective.
