# Interpretation
Choosing the uniform distribution corresponds to assuming that all elementary outcomes are equally likely, a reasonable assumption when no physical asymmetry exists and when the experiment is deemed fair (e.g., a fair coin or unbiased die).  However, if empirical data indicate different probabilities (such as the birth ratio of boys to girls being approximately 0.513), a uniform distribution would be inappropriate and a different distribution function should be used.  Uniform distributions arise naturally from symmetry arguments but are not mandated by the axioms of probability.

When a random variable X is said to be uniformly distributed, it means that the experiment from which X is derived gives each possible value the same chance of being observed.  This is the most symmetric and unbiased probability assignment on a finite set, and it is the baseline against which more complex distributions are measured.  In the algorithmic description, the uniform distribution is realized by the fact that the random number generator rnd produces values with equal density over (0, 1), and scaling by n followed by the floor operation preserves this equality across the integer outcomes.
