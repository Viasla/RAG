# Examples
1. Aspirin example – Suppose 60 % of ordinary aspirin cures headaches and the new drug is claimed to improve effectiveness. With a sample size n=100, the critical values m=69 and m=73 are identified: m=69 is the smallest value that keeps the type 1 error below 5 % and m=73 is the largest that keeps the type 2 error below 5 %. Choosing m between 69 and 73 balances the two errors. 2. If the manufacturer requires the chance of a type 2 error to be 1 % instead of 5 %, the text states that the number of trials n would have to be increased (see Exercise 28).
