# Properties
For any event \(E\subseteq\Omega\), its probability is \(P(E)=\sum_{\omega\in E} m(\omega)\), where \(m\) is the distribution function.

The probability of an elementary event \(\{\omega\}\) equals the probability mass assigned to that outcome: \(P(\{\omega\})=m(\omega)\).

Since every subset of \(\Omega\) is an event, events are closed under the usual set operations (union, intersection, complement).
